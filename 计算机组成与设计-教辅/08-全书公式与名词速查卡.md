## 一、全部公式一览

### 第 1 章 性能与成本

| 公式 | 说明 |
|---|---|
| 时钟频率 = 1 / 时钟周期 | 互为倒数 |
| **CPU执行时间 = 指令数 × CPI × 时钟周期** | 全书第一公式 |
| 性能X ÷ 性能Y = 执行时间Y ÷ 执行时间X | "n 倍快" |
| MIPS = 指令数 ÷ (执行时间 × 10⁶) | 有缺陷的指标 |
| 芯片成本 = 晶圆成本 ÷ (每晶圆芯片数 × 成品率) | 制造成本 |
| 动态功耗 ∝ 容性负载 × 电压² × 开关频率 | 功耗墙 |

### 第 3 章 算术

| 公式 | 说明 |
|---|---|
| a − b = a + (~b + 1) | 补码减法 |
| 溢出 ⟺ 正+正→负 或 负+负→正 | 符号判定 |
| 值 = (−1)^S × (1.Frac) × 2^(Exp−Bias) | 规格化浮点数 |
| 值 = (−1)^S × (0.Frac) × 2^(1−Bias) | 非规格化数 |
| Exp = 真指数 + Bias(单 127 / 双 1023) | 偏阶编码 |
| 浮点乘法指数:Exp = Exp₁ + Exp₂ − Bias | 去掉重复偏阶 |
| 行波进位延迟 ≈ 2n 级门延迟 | 加法器性能 |

### 第 4 章 处理器

| 公式 | 说明 |
|---|---|
| 流水线执行时间 ≈ (指令数 + 级数 − 1) × 周期 | 五级流水线 |
| 理想加速比 ≈ 级数 | 五级 ≈ 5 倍 |
| 理想 CPI = 1 / 发射宽度 | 多发射 |
| 单周期执行时间 = 指令数 × 最长指令时间 | 单周期基线 |

### 第 5 章 存储器

| 公式 | 说明 |
|---|---|
| **AMAT = 命中时间 + 缺失率 × 缺失代价** | 平均访存时间 |
| 多级:AMAT = T₁ + 缺₁ × (T₂ + 缺₂ × T₃) | 两级 cache |
| 块数 = cache 容量 ÷ 块大小 | 直接映射 |
| 索引位数 = log₂(块数 ÷ 路数) | 组相联 |
| 偏移位数 = log₂(块大小) | 字节计 |
| 标记位数 = 地址位 − 索引位 − 偏移位 | 地址划分 |
| 优化收益 = 降低的缺失率 × 缺失代价 | 权衡 |

### 第 6 章 并行

| 公式 | 说明 |
|---|---|
| **加速比 = 1 / [(1−P) + P/N]** | Amdahl 定律 |
| 加速比极限 = 1 / (1−P) | N→∞ 的天花板 |

## 三、MIPS 指令速查(完整版见第 2 章)

| 类别 | 指令 | 功能 |
|---|---|---|
| 算术 | add / sub / addi / addu / subu / addiu / mul | 加减(溢出检测与否) |
| 乘除 | mult / div → mfhi / mflo | 积/商入 Hi/Lo |
| 逻辑 | and / or / nor / andi / ori | 按位运算、掩码 |
| 移位 | sll / srl / sra | 左移 / 逻辑右移 / 算术右移 |
| 访存 | lw / sw / lb / lbu / sb / lh / lhu / sh / lui | 字/字节/半字、装载高 16 位 |
| 比较 | slt / sltu / slti / sltiu | 小于置位(有/无符号) |
| 分支 | beq / bne | 相等/不等则跳(PC 相对) |
| 跳转 | j / jal / jr | 无条件 / 调用 / 返回 |
| 同步 | ll / sc | 原子交换 |
| 浮点 | lwc1 / swc1 / add.s / add.d / c.eq.s / bc1t | 浮点访存、运算、比较分支 |
| 伪指令 | move / li / la / blt / bgt / ble / bge | 汇编器展开 |

**指令格式速记**:
- R 型:`op(6) rs(5) rt(5) rd(5) shamt(5) funct(6)`
- I 型:`op(6) rs(5) rt(5) imm(16)`
- J 型:`op(6) addr(26)`

**关键编码**:R 型 op=0;add funct=32、sub=34、and=36、or=37、nor=39、slt=42、jr=8、sll=0、srl=2、sra=3;j=2、jal=3、beq=4、bne=5、addi=8、andi=12、ori=13、slti=10、lw=35、sw=43。

## 四、单周期控制信号表(第 4 章必考)

| 信号 | R型 | lw | sw | beq |
|---|---|---|---|---|
| RegDst | 1 | 0 | × | × |
| ALUSrc | 0 | 1 | 1 | 0 |
| MemtoReg | 0 | 1 | × | × |
| RegWrite | 1 | 1 | 0 | 0 |
| MemRead | 0 | 1 | 0 | 0 |
| MemWrite | 0 | 0 | 1 | 0 |
| Branch | 0 | 0 | 0 | 1 |
| ALUOp | 10 | 00 | 00 | 01 |

**ALUOp 含义**:00=加(算地址)、01=减(比分支)、10=看 funct。

## 五、冒险解决速记(第 4 章必考)

| 冒险 | 解决 | 代价 |
|---|---|---|
| ALU 结果被后 1~2 条用 | 转发(EX/MEM 或 MEM/WB) | 0 周期 |
| load 结果紧跟使用(load-use) | 阻塞 1 拍 + 转发 | 1 周期 |
| 分支方向未知 | ID 段提前判断 + 预测不跳 + 猜错冲刷 | 猜错 1 周期 |
