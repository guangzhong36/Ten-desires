§3.1 预备:LTI 系统对复指数输入的响应

直觉先行:什么是"特征函数"?

在线性代数中,矩阵作用于特征向量只改变其长度:\(Av=\lambda v\)。这里完全类似:特征函数是"经过系统后形状不变、只被乘一个复数"的信号。复指数 \(e^{st}\)(离散:\(z^n\))正是 LTI 系统的特征函数——正弦波进 LTI 系统,出来的仍是同一频率的正弦波,只是幅度变了、相位挪了。系统不可能凭空造出新频率,这就是线性与时不变的深层含义。

验证(连续时间):设输入 \(x(t)=e^{st}\),输出:

特征函数关系 \[ y(t) = \int h(\tau)\, e^{s(t-\tau)} d\tau = e^{st} \underbrace{\int h(\tau)\, e^{-s\tau} d\tau}_{H(s)} = H(s)\, e^{st} \]

\(H(s)\) 称为系统的系统函数(第9章主角);当 \(s=j\omega\)(纯虚数,对应正弦)时,\(H(j\omega)\) 就是频率响应:

频率响应 \[ H(j\omega) = \int_{-\infty}^{+\infty} h(\tau)\, e^{-j\omega\tau}\, d\tau, \qquad e^{j\omega t} \xrightarrow{\;\text{LTI}\;} H(j\omega)\, e^{j\omega t} \]

离散时间完全平行:\(z^n \to H(z)z^n\),其中 \(H(z)=\sum_k h[k]z^{-k}\);令 \(z=e^{j\omega}\) 得 \(H(e^{j\omega})=\sum_k h[k]e^{-j\omega k}\)。0 基础解读:\(H(j\omega)\) 是个复数,可写成 \(H(j\omega)=|H(j\omega)|e^{j\angle H(j\omega)}\):模 \(|H|\) 是系统对频率 \(\omega\) 的增益,辐角 \(\angle H\) 是相移。

本章思想主线(务必记牢)

① 周期信号可拆成复指数之和:\(x(t)=\sum_k a_k e^{jk\omega_0 t}\);② 系统对每一项只乘一个数:\(e^{jk\omega_0 t}\to H(jk\omega_0)e^{jk\omega_0 t}\);③ 线性叠加得输出:\(y(t)=\sum_k a_k H(jk\omega_0) e^{jk\omega_0 t}\)。即输出的傅里叶系数 \(b_k = a_k \cdot H(jk\omega_0)\)——频域乘法。三步走,贯穿本章。

§3.2 连续时间周期信号的傅里叶级数(CTFS)

直觉先行:把周期信号"拆成"一组匀速旋转的指针

\(e^{jk\omega_0 t}\) 是转速为 \(k\omega_0\) 的旋转指针:\(k=0\) 是不动的直流分量,\(k=\pm1\) 是基波(每秒转 \(\omega_0\) 弧度),\(k=\pm2\) 是二次谐波……傅里叶级数说:任何周期信号都是一组转速成整数倍的旋转指针的叠加,系数 \(a_k\) 告诉你第 \(k\) 根指针有多长、初始指向哪。方波、锯齿波看似与正弦无关,其实都是正弦的"合奏"。

指数形式定义:基波周期为 \(T_0\)(基波频率 \(\omega_0=2\pi/T_0\))的周期信号:

连续时间傅里叶级数(合成式 + 分析式) \[ x(t) = \sum_{k=-\infty}^{+\infty} a_k\, e^{jk\omega_0 t}, \qquad a_k = \frac{1}{T_0}\int_{T_0} x(t)\, e^{-jk\omega_0 t}\, dt \]

0 基础解读:第二式(分析式)把信号"拆开":与 \(e^{-jk\omega_0 t}\) 相乘再积分,相当于问"\(x(t)\) 里含有多少转速为 \(k\omega_0\) 的分量"。\(\int_{T_0}\) 表示在任意一个完整周期上积分(起点随意,结果相同)。\(a_0\) 就是信号的直流分量(平均值)。

例题 3.1 周期方波的傅里叶级数(必会题)

设 \(x(t)\) 为周期 \(T_0=4\) 的方波:\(|t|<1\) 时取 1,\(1<|t|<2\) 时取 0,求 \(a_k\)。

  1. 基波频率 \(\omega_0=2\pi/4=\pi/2\)。选积分区间 \([-2,2]\)。
  2. 被积函数只在 \(|t|<1\) 非零:\(a_k=\dfrac{1}{4}\displaystyle\int_{-1}^{1} e^{-jk\frac{\pi}{2}t}\,dt\)。
  3. 积分:\(=\dfrac{1}{4}\cdot\dfrac{e^{-jk\frac{\pi}{2}t}}{-jk\pi/2}\Big|_{-1}^{1}=\dfrac{1}{4}\cdot\dfrac{2\sin(k\pi/2)}{k\pi/2}=\dfrac{\sin(k\pi/2)}{k\pi}\),\(k\neq0\)。
  4. \(k=0\) 单独算(直流):\(a_0=\dfrac{1}{4}\int_{-1}^{1}dt=\dfrac{1}{2}\)。
  5. 归纳:\(a_k=\dfrac{\sin(k\pi/2)}{k\pi}\;(k\neq0)\),即 \(a_1=1/\pi\),\(a_2=0\),\(a_3=-1/(3\pi)\),\(a_4=0\),\(a_5=1/(5\pi)\),……偶次谐波全为零(后面 §3.4 会解释这是"半波对称"的功劳)。

3.2.1 收敛条件与 Gibbs 现象

周期信号满足 Dirichlet 条件(①任一周期绝对可积;②任一周期内有限个极值;③有限个间断点)时,傅里叶级数收敛:连续点处收敛于信号值,间断点处收敛于两侧值的平均。

图 3-1 Gibbs 现象:方波的部分和近似(N 为保留的最高次谐波)。N 增大时波形越来越像方波,但跳变处始终有约 9% 的过冲尖峰——尖峰不会随 N→∞ 消失,只是变窄

0 基础解读:Gibbs 现象是"数学的脾气":用连续光滑的正弦波去拼一个跳变,跳变处永远拼不完美,总会鼓起一个约 9% 的"包"。工程含义:用有限项近似方波时,跳变附近的过冲是傅里叶级数的固有属性,不是计算错误;若要消除,需要用其他方法(如加窗,进阶内容)。

§3.3 CTFS 的性质

设 \(x(t)\leftrightarrow a_k\)(双向箭头表示"傅里叶级数对"),以下性质与第 1 章的自变量变换一一呼应:

性质信号系数
线性\(Ax(t)+By(t)\)\(Aa_k+Bb_k\)
时移\(x(t-t_0)\)\(e^{-jk\omega_0 t_0}a_k\)(幅度不变,相位挪)
时间反转\(x(-t)\)\(a_{-k}\)
尺度变换\(x(\alpha t)\)(周期变 \(T_0/\alpha\))系数不变,基频变 \(\alpha\omega_0\)
相乘\(x(t)y(t)\)\(a_k*b_k=\sum_l a_l b_{k-l}\)(系数做离散卷积!)
共轭对称\(x(t)\) 为实信号\(a_k=a_{-k}^*\)(幅度偶对称,相位奇对称)
Parseval 定理\(\dfrac{1}{T_0}\int_{T_0}|x(t)|^2dt\)\(=\sum_k |a_k|^2\)(时域平均功率=频域系数功率和)

0 基础解读(挑三条最重要的):①时移:波形挪一挪,每个系数的幅度不变,只多乘一个单位模的相位因子——"换挡不换速";②相乘:时域相乘对应频域卷积,这是第 4 章卷积性质与第 8 章调制的伏笔;③Parseval:能量(功率)在时域算与在频域算结果相同,它是"守恒律",也是检查计算的利器。

§3.4 对称性:让计算量减半再减半

直觉先行:对称的波形,频谱也对称

偶信号由"纯余弦"构成(余弦是偶函数),奇信号由"纯正弦"构成(正弦是奇函数)。波形若上下对称(半波对称),则只有奇次谐波。这三条规律把大量积分直接判为 0,是考试与工程中最重要的"省力法则"。

信号对称性系数特点
偶信号 \(x(t)=x(-t)\)\(a_k\) 全为实数:级数只有余弦项 \(x(t)=a_0+2\sum_{k\ge1} a_k\cos(k\omega_0 t)\)
奇信号 \(x(t)=-x(-t)\)\(a_k\) 全为纯虚数:级数只有正弦项,\(a_0=0\)
半波对称 \(x(t)=-x(t+T_0/2)\)偶次谐波为零:\(a_k=0\;(k\) 为偶数\()\)
例题 3.2 三角形式的换算

已知 \(a_1=\dfrac{3}{2}-\dfrac{j}{2}\),\(a_{-1}=\dfrac{3}{2}+\dfrac{j}{2}\)(其余为零),写出 \(x(t)\) 的余弦形式。

  1. 实信号系数共轭对称 ✓。合成:\(x(t)=a_1 e^{j\omega_0 t}+a_{-1}e^{-j\omega_0 t}\)。
  2. 利用 \(\cos\theta=\dfrac{e^{j\theta}+e^{-j\theta}}{2}\),\(\sin\theta=\dfrac{e^{j\theta}-e^{-j\theta}}{2j}\) 化简。
  3. \(x(t)=3\cos\omega_0 t+\sin\omega_0 t\)。对照第1章公式:\(c_k=2\,\mathrm{Re}\{a_k\}=3\),\(d_k=-2\,\mathrm{Im}\{a_k\}=1\) ✓。

§3.5 傅里叶级数与 LTI 系统:滤波

回到 §3.1 的三步走。输入周期信号 \(x(t)=\sum_k a_k e^{jk\omega_0 t}\),输出:

周期输入下 LTI 系统的输出 \[ y(t) = \sum_{k=-\infty}^{+\infty} a_k\, H(jk\omega_0)\, e^{jk\omega_0 t} \quad\Longrightarrow\quad b_k = a_k\, H(jk\omega_0) \]

0 基础解读:系统对每个谐波 \(k\omega_0\) 的增益是 \(|H(jk\omega_0)|\)、相移是 \(\angle H(jk\omega_0)\)。若 \(|H(jk\omega_0)|\) 对某些 \(k\) 大、对另一些 \(k\) 小,输出里相应谐波就被"放大/削弱"——这就是滤波。滤波器 = 按频率修改配方。

例题 3.3 低通滤波改变方波

例题 3.1 的方波通过理想低通滤波器 \(H(j\omega)\):\(|\omega|<3\omega_0\) 时增益 1,其余为 0(相移为 0)。求输出。

  1. 方波系数:\(a_0=1/2\),\(a_{\pm1}=\pm1/\pi\),\(a_{\pm3}=\mp1/(3\pi)\),\(a_{\pm5}=\pm1/(5\pi)\),……
  2. 滤波器只放行 \(|k\omega_0|<3\omega_0\) 即 \(k=-2,-1,0,1,2\) 的谐波。
  3. 输出:\(y(t)=\dfrac{1}{2}+\dfrac{1}{\pi}(e^{j\omega_0 t}-e^{-j\omega_0 t})=\dfrac{1}{2}+\dfrac{2}{\pi}\cos\omega_0 t\)(只有直流 + 基波,偶次本来就是零)。
  4. 对照图 3-1 中 \(N=1\) 的曲线——低通滤波输出正是那个"圆润"的波形。

§3.6 离散时间傅里叶级数(DTFS)

周期为 \(N\) 的序列 \(x[n]\)(基频 \(2\pi/N\))也有傅里叶级数,但与 CT 有三处根本不同:

离散时间傅里叶级数(DTFS) \[ x[n] = \sum_{k=\langle N\rangle} a_k\, e^{jk\frac{2\pi}{N}n}, \qquad a_k = \frac{1}{N}\sum_{n=\langle N\rangle} x[n]\, e^{-jk\frac{2\pi}{N}n} \]
  • 不同点 1:系数只有 \(N\) 个。因为 \(e^{j(k+N)\frac{2\pi}{N}n}=e^{jk\frac{2\pi}{N}n}\)——相差 \(N\) 的谐波是同一个序列(第 1 章的周期折叠),所以级数只有 \(N\) 项,求和记号 \(\langle N\rangle\) 表示"任意连续 \(N\) 项"
  • 不同点 2:系数 \(a_k\) 本身以 \(N\) 为周期。\(a_{k+N}=a_k\),画频谱只需画 \(N\) 个
  • 不同点 3:有限和,无收敛问题。没有 Gibbs 现象,级数在每一点都精确成立
例题 3.4 直接读出 DTFS 系数(书例 3.9)

设 \(x[n]=1+\sin\left(\dfrac{2\pi n}{N}\right)+3\cos\left(\dfrac{2\pi n}{N}\right)+\cos\left(\dfrac{4\pi n}{N}+\dfrac{\pi}{2}\right)\),求系数 \(a_k\)。

  1. 全部化归复指数:\(\sin\theta=\dfrac{e^{j\theta}-e^{-j\theta}}{2j}\),\(\cos\theta=\dfrac{e^{j\theta}+e^{-j\theta}}{2}\),且 \(\cos(\theta+\pi/2)=-\sin\theta\)。
  2. \(x[n]=1+\left(\dfrac{3}{2}-\dfrac{j}{2}\right)e^{j\frac{2\pi}{N}n}+\left(\dfrac{3}{2}+\dfrac{j}{2}\right)e^{-j\frac{2\pi}{N}n}+\dfrac{j}{2}e^{j\frac{4\pi}{N}n}-\dfrac{j}{2}e^{-j\frac{4\pi}{N}n}\)。
  3. 读出:\(a_0=1\),\(a_1=\dfrac{3}{2}-\dfrac{j}{2}\),\(a_{-1}=\dfrac{3}{2}+\dfrac{j}{2}\),\(a_2=\dfrac{j}{2}\),\(a_{-2}=-\dfrac{j}{2}\),其余为 0。
  4. 验证共轭对称:\(a_1=a_{-1}^*\) ✓,\(a_2=a_{-2}^*\) ✓(实信号)。

§3.9 自测题(答案附后)

求 \(x(t)=\cos\omega_0 t\) 的傅里叶级数系数 \(a_k\)。

答案与解析

\(\cos\omega_0 t=\dfrac{1}{2}e^{j\omega_0 t}+\dfrac{1}{2}e^{-j\omega_0 t}\) → \(a_1=a_{-1}=\dfrac{1}{2}\),其余为 0。心得:余弦 = 两根反向旋转的指针,各占一半长度——这是全书最常用的一个"变换对"。

例题 3.1 的方波中,\(a_2\)、\(a_4\) 为什么为零?若把方波右移 \(1/2\)(半个脉冲宽度),系数如何变化?

答案与解析

偶次谐波为零是因为信号满足半波对称 \(x(t+2)=-x(t)\)。右移 \(1/2\) 后按性质:\(a_k'=e^{-jk\omega_0/2}a_k=e^{-jk\pi/4}\cdot\dfrac{\sin(k\pi/2)}{k\pi}\)——幅度完全不变,每个谐波只是相位转动了 \(k\pi/4\)。波形挪动不改变频谱形状,只改相位。

用 Parseval 定理验证:\(x(t)=\cos\omega_0 t\) 的平均功率等于系数模方和。

答案与解析

时域:\(\dfrac{1}{T_0}\int_{T_0}\cos^2\omega_0 t\,dt=\dfrac{1}{2}\)。频域:\(\sum_k|a_k|^2=\dfrac{1}{4}+\dfrac{1}{4}=\dfrac{1}{2}\) ✓。正弦波的平均功率是幅度的平方之半,Parseval 说这个功率平均分给正负频率两根指针。

求 \(x[n]=\cos\left(\dfrac{2\pi n}{5}\right)\) 的 DTFS 系数(周期 N=5)。

答案与解析

\(\cos(2\pi n/5)=\dfrac{1}{2}e^{j\frac{2\pi}{5}n}+\dfrac{1}{2}e^{-j\frac{2\pi}{5}n}\),而 \(e^{-j\frac{2\pi}{5}n}=e^{j\frac{8\pi}{5}n}=e^{j4\frac{2\pi}{5}n}\)。所以 \(a_1=a_4=\dfrac{1}{2}\),其余为 0。注意系数按 \(k=0,1,2,3,4\) 排列时,负频率"折叠"到 \(k=N-1\) 处——这是 DT 频谱与 CT 频谱画法上的重要差别。

周期信号 \(x(t)=\cos t+\cos 3t\) 通过 LTI 系统,已知 \(H(j1)=2\),\(H(j3)=0\),\(H(j\omega)=H(-j\omega)\) 为实。求输出。

答案与解析

逐次谐波乘增益:基波 \(\cos t\to 2\cos t\)(幅度翻倍、相位不变);三次谐波被 \(H(j3)=0\) 完全滤除 → \(y(t)=2\cos t\)。这就是"滤波"的最小完整例子。

§3.10 动手实验与下章预告

动手实验(MATLAB / Octave,10 分钟看见 Gibbs)
t = linspace(-pi, pi, 1000);
sq = (abs(t) < pi/2);                      % 目标方波
