§9.1 定义与动机

直觉先行:给不听话的信号"打一针镇定剂"

傅里叶变换要求信号绝对可积,但 \(e^{2t}u(t)\) 这类指数增长信号积分发散。办法:先乘一个指数衰减因子 \(e^{-\sigma t}\) 把它"压下去",再做傅里叶变换。这个"复合操作"就是拉普拉斯变换:先镇压,再分析。\(j\omega\) 推广为 \(s=\sigma+j\omega\),傅里叶变换成为 \(s\) 平面虚轴上的特例。

(双边)拉普拉斯变换 \[ X(s) = \int_{-\infty}^{+\infty} x(t)\, e^{-st}\, dt, \qquad s = \sigma + j\omega \]

收敛域(ROC):使积分收敛的全体 \(s\) 的集合。若 ROC 包含 \(j\omega\) 轴(即某个 \(\sigma=0\) 情形),则信号存在傅里叶变换,且 \(X(j\omega)=X(s)\big|_{s=j\omega}\)——在 ROC 内做替换即可。0 基础解读:ROC 就是"\(e^{-\sigma t}\) 要多强才能压住信号"的量化描述:增长越快的信号,需要越大的 \(\sigma\),ROC 越靠右。

例题 9.1 推导 \(e^{-at}u(t)\) 的拉氏变换(必会)
  1. \(X(s)=\displaystyle\int_0^{\infty} e^{-at}e^{-st}dt=\int_0^{\infty} e^{-(s+a)t}dt\)。
  2. 收敛条件:\(\mathrm{Re}\{s+a\}>0\) ⟺ \(\mathrm{Re}\{s\}>-a\)(否则 \(t\to\infty\) 时被积函数不衰减)。
  3. 积分:\(X(s)=\dfrac{1}{s+a}\),ROC: \(\mathrm{Re}\{s\}>-a\)(右半平面)。
  4. 对照 FT:当 \(-a<0\)(即 \(a>0\))时 ROC 含 \(j\omega\) 轴,\(X(j\omega)=\dfrac{1}{a+j\omega}\) 与第 4 章结果一致 ✓。当 \(a<0\) 时信号无 FT,但仍有拉氏变换——这就是拉氏变换的威力。

§9.2 ROC:同样的公式,不同的信号

例题 9.2 一个 \(X(s)\),三种 ROC,三个信号

求 \(-e^{-at}u(-t)\) 与 \(e^{-a|t|}\) 的拉氏变换,与例 9.1 对照。

  1. 左边信号 \(-e^{-at}u(-t)\):\(X(s)=\dfrac{1}{s+a}\),但收敛条件反转为 \(\mathrm{Re}\{s\}<-a\)(左半平面)。
  2. 双边信号 \(e^{-a|t|}=e^{-at}u(t)+e^{at}u(-t)\):两个极点 \(\pm a\),ROC 是两者的交集:带 \(-a<\mathrm{Re}\{s\}
  3. 震撼结论:三个完全不同信号的拉氏变换式一模一样,唯一区别是 ROC!所以必须记住:\(X(s)\) 不写 ROC,等于没说。
图 9-1 相同 \(X(s)=1/(s+a)\) 的三种 ROC(阴影区):(a) 右边信号 → 右半面;(b) 左边信号 → 左半面;(c) 双边信号 → 带状。虚线与 × 表示极点位置

ROC 的三条黄金性质:

  • 形状:ROC 总是平行于 \(j\omega\) 轴的带(可以是半平面或全平面)
  • 边界:有理变换的 ROC 边界由极点界定,ROC 内绝无极点
  • 判 FT:ROC 包含 \(j\omega\) 轴 ⟺ 信号存在傅里叶变换

有理变换 \(X(s)=N(s)/D(s)\):分子根为零点(画 ○),分母根为极点(画 ×)。零极点图 + ROC 完全刻画信号。常用变换对:

§9.4 反变换:部分分式 + ROC 定向

例题 9.3 部分分式反变换(本章最重要流程)

\(X(s)=\dfrac{1}{(s+1)(s+2)}\),分别求 ROC 为 (a) \(\mathrm{Re}\{s\}>-1\);(b) \(-2<\mathrm{Re}\{s\}<-1\);(c) \(\mathrm{Re}\{s\}<-2\) 时的 \(x(t)\)。

  1. 分解:\(X(s)=\dfrac{1}{s+1}-\dfrac{1}{s+2}\)。
  2. (a) ROC 在两个极点右边 → 两项都是右边信号:\(x(t)=(e^{-t}-e^{-2t})u(t)\)。
  3. (b) ROC 是带:\(s=-1\) 在其右边 → 该项取左边信号;\(s=-2\) 在其左边 → 该项取右边信号:\(x(t)=-e^{-t}u(-t)-e^{-2t}u(t)\)。
  4. (c) ROC 在两个极点左边 → 都是左边信号:\(x(t)=(-e^{-t}+e^{-2t})u(-t)\)。
  5. 心法:极点 在 ROC 右边 → 该项是右边信号(\(u(t)\));极点 在 ROC 左边 → 左边信号(\(u(-t)\),注意配负号)。

§9.5 系统函数与稳定性分析

系统函数 \(H(s)\):系统冲激响应的拉氏变换,满足 \(Y(s)=H(s)X(s)\)。两条核心判据:

必背判据
  • 因果性:系统因果 ⟺ \(H(s)\) 的 ROC 是某个右半平面(且为最右极点之右)
  • 稳定性:系统稳定 ⟺ ROC 包含 \(j\omega\) 轴。对因果系统:稳定 ⟺ 全部极点都在左半平面(\(\mathrm{Re}\{极点\}<0\))
例题 9.4 由微分方程求 \(H(s)\) 并判断稳定性

系统 \(y''+3y'+2y=x(t)\),求因果系统的 \(H(s)\),判断稳定性。

  1. 两边取拉氏变换:\((s^2+3s+2)Y(s)=X(s)\)(初始松弛)。
  2. \(H(s)=\dfrac{1}{s^2+3s+2}=\dfrac{1}{(s+1)(s+2)}\)。
  3. 因果 → ROC: \(\mathrm{Re}\{s\}>-1\)(最右极点之右),且包含 \(j\omega\) 轴 → 稳定。
  4. 验证:反变换 \(h(t)=(e^{-t}-e^{-2t})u(t)\),\(\int_0^\infty|h|dt<\infty\) ✓ 与第 2 章判据一致。
  5. 对比:若分母是 \(s^2-s-2=(s+1)(s-2)\),极点 \(s=2\) 在右半平面,因果系统 ROC \(\mathrm{Re}\{s\}>2\) 不含 \(j\omega\) 轴 → 不稳定(输出指数发散)。

§9.9 自测题(答案附后)

求 \(x(t)=e^{-3t}u(t)+e^{-t}u(t)\) 的拉氏变换与 ROC。

答案与解析

\(X(s)=\dfrac{1}{s+3}+\dfrac{1}{s+1}=\dfrac{2s+4}{(s+1)(s+3)}\),ROC = 两者交集:\(\mathrm{Re}\{s\}>-1\)。包含 \(j\omega\) 轴 → 信号存在傅里叶变换。

\(X(s)=\dfrac{1}{(s+1)(s+2)}\),ROC 为 \(-2<\mathrm{Re}\{s\}<-1\),求 \(x(t)\) 并判断其是否有傅里叶变换。

答案与解析

分解 \(\dfrac{1}{s+1}-\dfrac{1}{s+2}\)。ROC 是带:极点 −1 在带右边 → \(-e^{-t}u(-t)\);极点 −2 在带左边 → \(-e^{-2t}u(t)\)。合:\(x(t)=-e^{-t}u(-t)-e^{-2t}u(t)\)。ROC 含 \(j\omega\) 轴(虚轴在带内)→ FT 存在:\(X(j\omega)=\dfrac{1}{(j\omega+1)(j\omega+2)}\)。

系统 \(H(s)=\dfrac{s-1}{(s+1)(s+2)}\),若系统因果,判断其稳定性。

答案与解析

极点 −1、−2 全在左半平面;因果系统 ROC 为 \(\mathrm{Re}\{s\}>-1\),包含 \(j\omega\) 轴 → 稳定。注意零点 \(s=1\) 在右半平面不影响稳定性——稳定性只看极点位置(对因果系统)。

用拉氏变换解:\(y'(t)+2y(t)=x(t)\),\(x(t)=u(t)\),\(y(0^-)=1\),求 \(y(t)\)。

答案与解析

单边拉氏:\(sY(s)-y(0^-)+2Y(s)=\dfrac{1}{s}\) → \(Y(s)=\dfrac{1}{s(s+2)}+\dfrac{1}{s+2}=\dfrac{1}{2}\left(\dfrac{1}{s}-\dfrac{1}{s+2}\right)+\dfrac{1}{s+2}=\dfrac{1/2}{s}+\dfrac{1/2}{s+2}\)。反变换:\(y(t)=\dfrac{1}{2}+\dfrac{1}{2}e^{-2t}\),\(t\ge0\)。验证:\(y(0^+)=1\) ✓,稳态 \(1/2\) ✓(直流增益 \(H(0)=1/2\))。

为什么说"\(X(s)\) 不写 ROC 等于没说"?举一个具体例子。

答案与解析

因为同一个 \(1/(s+a)\) 对应无穷多个信号(例 9.2 中的右/左/双边三种)。教材语境下默认"因果"(最右极点之右的 ROC),但考试与工程中必须明确 ROC:反变换、稳定性判断、FT 存在性全部依赖它。约定:凡涉及因果系统,ROC 取最右极点之右。
