§10.1 定义与收敛域

直觉先行:\(z\) 是"复旋转 + 缩放"的旋钮

DTFT 用 \(e^{j\omega n}\) 分解序列——只有单位模的复指数。若序列增长(如 \(2^n u[n]\)),单位模的试探信号"压不住"它,求和发散。Z 变换把试探信号换成 \(z^n=(re^{j\omega})^n=r^n e^{j\omega n}\):多出一个旋钮 \(r\) 控制"缩放"。选对 \(|z|\) 的范围(ROC),就能分析任何指数增长信号。这正是拉氏变换"乘衰减因子"的离散版本。

(双边)Z 变换 \[ X(z) = \sum_{n=-\infty}^{+\infty} x[n]\, z^{-n}, \qquad z = r\, e^{j\omega} \]

0 基础解读:①ROC 是使求和收敛的 \(z\) 的集合,形状是圆环(只与 \(|z|\) 有关,与幅角无关);②ROC 含单位圆(|z|=1)时,序列存在 DTFT,且 \(X(e^{j\omega})=X(z)\big|_{z=e^{j\omega}}\);③与拉氏变换的对应:虚轴 \(j\omega\) ↔ 单位圆,右半平面 ↔ 单位圆外,左半平面 ↔ 单位圆内。

例题 10.1 推导 \(a^n u[n]\) 的 Z 变换(必会)
  1. \(X(z)=\displaystyle\sum_{n=0}^{\infty} a^n z^{-n}=\sum_{n=0}^{\infty}(az^{-1})^n\)。
  2. 几何级数收敛条件:\(|az^{-1}|<1\) ⟺ \(|z|>|a|\)(单位圆外)。
  3. 求和:\(X(z)=\dfrac{1}{1-az^{-1}}=\dfrac{z}{z-a}\),ROC: \(|z|>|a|\)。
  4. 对照 DTFT:\(|a|<1\) 时 ROC 含单位圆,\(X(e^{j\omega})=\dfrac{1}{1-ae^{-j\omega}}\) 与第 5 章一致 ✓;\(|a|>1\) 时无 DTFT 但有 Z 变换。
例题 10.2 同样的式子,不同的序列

求 \(-a^n u[-n-1]\)(左边序列)的 Z 变换。

  1. \(X(z)=-\displaystyle\sum_{n=-\infty}^{-1} a^n z^{-n}=-\sum_{m=1}^{\infty} a^{-m}z^{m}\)(令 \(m=-n\))。
  2. 收敛条件:\(|a^{-1}z|<1\) ⟺ \(|z|<|a|\)(圆内)。
  3. 结果:\(X(z)=\dfrac{1}{1-az^{-1}}\)——与例 10.1 的变换式完全相同,只是 ROC 相反!
  4. 心法(与第9章同款):圆外 ROC → 右边序列;圆内 ROC → 左边序列;圆环 → 双边序列。写 Z 变换必须带 ROC。
图 10-1 相同 \(X(z)=1/(1-az^{-1})\)(极点 \(z=a=0.5\))的三种 ROC:(a) 圆外 → 右边序列;(b) 圆内 → 左边序列;(c) 圆环(两极点之间)→ 双边序列 \(a^{|n|}\)。虚线圆为极点位置,浅灰大圆为单位圆

§10.2 反变换:部分分式 + ROC 定向

例题 10.3 部分分式反变换(最重要流程)

\(X(z)=\dfrac{1}{(1-\frac{1}{2}z^{-1})(1-\frac{1}{3}z^{-1})}\),ROC: \(|z|>\dfrac{1}{2}\),求 \(x[n]\)。

  1. 以 \(z^{-1}\) 为变量做部分分式:\(X(z)=\dfrac{A}{1-\frac{1}{2}z^{-1}}+\dfrac{B}{1-\frac{1}{3}z^{-1}}\),解得 \(A=3,\;B=-2\)。
  2. ROC \(|z|>1/2\) 在两个极点之外 → 两项都是右边序列。
  3. 查表反变换:\(x[n]=\left[3\left(\dfrac{1}{2}\right)^n-2\left(\dfrac{1}{3}\right)^n\right]u[n]\)。
  4. 心法:极点 在 ROC 内 → 该项对应右边序列;极点 在 ROC 外 → 左边序列(配负号、\(u[-n-1]\))。与第 9 章"极点在 ROC 右/左"同构,只是"内/外"替代"左/右"。

§10.3 系统函数与稳定性

系统函数 \(H(z)\):冲激响应的 Z 变换,\(Y(z)=H(z)X(z)\)。两条核心判据(对照第9章):

必背判据
  • 因果性:系统因果 ⟺ \(H(z)\) 的 ROC 是某个圆外区域(最外极点之外)
  • 稳定性:系统稳定 ⟺ ROC 包含单位圆。对因果系统:稳定 ⟺ 全部极点在单位圆内(\(|z_i|<1\))
例题 10.4 差分方程求 \(H(z)\) 与稳定性

系统 \(y[n]-a\,y[n-1]=x[n]\),求因果系统的 \(H(z)\),讨论稳定性。

  1. 取 Z 变换:\(Y(z)-az^{-1}Y(z)=X(z)\) → \(H(z)=\dfrac{1}{1-az^{-1}}=\dfrac{z}{z-a}\)。
  2. 极点 \(z=a\)。因果 → ROC: \(|z|>|a|\)。
  3. 稳定 ⟺ 单位圆在 ROC 内 ⟺ \(|a|<1\)。
  4. 物理图景:\(h[n]=a^n u[n]\);\(|a|<1\) 时响应逐拍衰减(稳定),\(|a|\ge1\) 时发散(不稳定)——与第 2 章"绝对可和"判据完全一致 ✓。

§10.4 几何法:从零极点图目测频率响应

直觉先行:频率响应是"距离之比"

把 \(H(z)=\dfrac{(z-c_1)(z-c_2)\cdots}{(z-d_1)(z-d_2)\cdots}\) 代入 \(z=e^{j\omega}\) 逐项取模:\(|H(e^{j\omega})|=\dfrac{|e^{j\omega}-c_1|\cdot|e^{j\omega}-c_2|\cdots}{|e^{j\omega}-d_1|\cdot|e^{j\omega}-d_2|\cdots}\)——每一项都是单位圆上的点 \(e^{j\omega}\) 到零点/极点的距离!幅度谱 = 零点距离之积 ÷ 极点距离之积:单位圆上的点靠近极点时距离小、\(|H|\) 大(峰);靠近零点时 \(|H|\) 小(谷)。

图 10-2 几何法读 \(|H(e^{j\omega})|=1/|e^{j\omega}-a|\):单位圆上距极点最近的 \(\omega=0\) 处幅度最大;随 \(\omega\) 增大距离变长、幅度下降——低通形状"一眼可见"
例题 10.5 用几何法解释一阶系统幅度谱

\(H(z)=\dfrac{1}{1-az^{-1}}\),\(0

  1. 极点 \(z=a\) 位于单位圆内正实轴上。
  2. \(|H(e^{j\omega})|=1/|e^{j\omega}-a|\):\(\omega=0\) 时单位圆上点 (1,0) 距极点最近 → \(|H|=1/(1-a)\) 最大。
  3. \(\omega=\pi\) 时点 (−1,0) 距极点最远 → \(|H|=1/(1+a)\) 最小。
  4. 故幅度随频率升高单调下降 → 低通;且 \(a\to1\) 时极点贴住单位圆,峰值 \(1/(1-a)\to\infty\),"谐振"愈尖锐——这就是第 5、6 章数值结论的几何本质。

§10.6 本章小结:最小必会清单

离开本章前,请确认能做到这 7 件事
  1. 推导 \(a^n u[n]\leftrightarrow1/(1-az^{-1})\) 及 ROC \(|z|>|a|\)(几何级数)
  2. 写出同式的左边序列版本与 ROC \(|z|<|a|\)(例 10.2)
  3. 部分分式反变换时,按"极点在 ROC 内/外"给每项定向(例 10.3 心法)
  4. 由 \(H(z)\) 判断因果(圆外)与稳定(单位圆在 ROC 内;因果时极点全在单位圆内)
  5. 由差分方程求 \(H(z)\),会求极点并讨论稳定性(例 10.4)
  6. 用几何法解释 \(|H(e^{j\omega})|\) 的峰谷(距离之比,例 10.5)
  7. 熟练完成与拉氏变换的对照翻译(带↔圆环、虚轴↔单位圆、右半面↔圆外)

§10.7 自测题(答案附后)

求 \(x[n]=\left(\dfrac{1}{2}\right)^n u[n]+\left(\dfrac{1}{3}\right)^n u[n]\) 的 Z 变换与 ROC。

答案与解析

\(X(z)=\dfrac{1}{1-\frac{1}{2}z^{-1}}+\dfrac{1}{1-\frac{1}{3}z^{-1}}\),ROC = 交集:\(|z|>\dfrac{1}{2}\)。含单位圆 → DTFT 存在(\(|a|<1\))。

\(X(z)=\dfrac{1}{1-\frac{1}{2}z^{-1}}\),ROC 为 \(|z|<\dfrac{1}{2}\),求 \(x[n]\),并判断其是否有 DTFT。

答案与解析

圆内 ROC → 左边序列:\(x[n]=-\left(\dfrac{1}{2}\right)^n u[-n-1]\)。ROC 不含单位圆 → 无 DTFT(序列在负方向指数增长)。

系统 \(H(z)=\dfrac{1}{1-2z^{-1}}\),若系统因果,判断稳定性。

答案与解析

极点 \(z=2\),在单位圆外。因果系统 ROC \(|z|>2\) 不含单位圆 → 不稳定(\(h[n]=2^n u[n]\) 发散)。延伸:若取反因果 ROC \(|z|<2\),则含单位圆、系统稳定——同一差分方程,因果性与稳定性不可兼得,这正是 ROC 选择的物理含义。

差分方程 \(y[n]-\dfrac{1}{2}y[n-1]=x[n]+\dfrac{1}{3}x[n-1]\),求因果系统的 \(H(z)\),写出零极点。

答案与解析

\(H(z)=\dfrac{1+\frac{1}{3}z^{-1}}{1-\frac{1}{2}z^{-1}}=\dfrac{z+\frac{1}{3}}{z-\frac{1}{2}}\)。零点 \(z=-1/3\),极点 \(z=1/2\)(单位圆内)→ 因果系统稳定。注意零点在单位圆内负实轴上,\(\omega=\pi\) 处距离最小 → 高频被"挖坑",这是一阶低通上加高阻的雏形。

用几何法说明:\(H(z)=\dfrac{1}{1+az^{-1}}\)(\(0

答案与解析

极点位于单位圆内负实轴。\(\omega=\pi\) 处单位圆上点 (−1,0) 距极点最近 → \(|H|=1/(1-a)\) 最大;\(\omega=0\) 处点 (1,0) 最远 → \(|H|=1/(1+a)\) 最小。幅度随频率升高而增大 → 高通。仅凭极点位置的正负号就判定了滤波器类型——几何法之美。
