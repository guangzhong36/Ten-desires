§4.1 树的概念:术语与一般树的实现

4.1.1 术语:根、父结点、子结点、兄弟、叶、深度、高度、路径

树的递归定义:树是结点的集合——要么是空集,要么由一个根结点加上若干棵互不相交的子树构成,每棵子树本身也是树。这决定了本章算法的递归写法。

图 4-1 一般树的术语
树的递归定义:树 = 根 + 互不相交的子树。
            树根(root)               ← 唯一没有父结点的结点
          /        \
    父结点A          父结点B          ← A、B 互为兄弟
    /      \              \
子结点C    子结点D      子结点E      ← C、D 的父结点都是 A
  /                  /
叶F                叶G              ← 叶:没有子结点的结点

深度从根往下数(根 0),高度从叶往上数(叶 0),树高 = 根的高度;路径长度 = 边数。n 个结点的树有 n−1 条边。方向相反,勿混淆。

记号说明(树高递归式,全书沿用)

height(空) = 0,height(v) = 1 + max(height(v.left), height(v.right))——它同时是定义、递推式和代码,§4.2 的求高函数就是逐字翻译。

4.1.2 一般树的实现:从 first_child+next_sibling 到 list 子结点容器

C 靠 firstChild+nextSibling 表达任意多的子结点;Python 用 list 保存——第3章 list 思想在树上的延续:

C 的写法(first_child + next_sibling)Python 的写法(list 子结点容器)
struct TreeNode { int val; struct TreeNode *firstChild, *nextSibling; };class TreeNode: self.children = []
遍历子结点:沿 nextSibling 链 while 循环遍历子结点:for 一句
访问第 k 个子结点要数 k 次指针children[k] 直接下标访问
插入子结点自己维护链接顺序children.append(c) 一行
忘记 free 子树 = 泄漏引用计数自动回收,无泄漏
示例 4-1 一般树结点:list 子结点容器
class TreeNode:
    def __init__(self, val):
        self.val = val
        self.children = []          # 子结点容器(list)

def print_children(n):              # 对照 C 的 nextSibling 链
    for c in n.children:            # for 一句遍历
        print(c.val, end=' ')

4.1.3 一般树 vs 二叉树

二叉树是"每个结点至多两个子结点,且区分左右"的树——只有一个子结点也要说清在左在右。BST、表达式树、堆(第6章)都依赖"左/右"语义。一般树与二叉树可互相转换:"长子变左子、兄弟变右子"正是 C 的 first_child+next_sibling。

§4.2 二叉树与四种遍历

4.2.1 二叉树的定义与递归三序遍历

二叉树要么为空,要么由根 + 左子树 + 右子树构成——直接翻译成结点类:

示例 4-2 二叉树结点与前/中/后序递归遍历
class BTNode:
    def __init__(self, val, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def preorder(n):                    # 前序:根 → 左 → 右
    if n is None: return
    print(n.val, end=' ')
    preorder(n.left)
    preorder(n.right)

def inorder(n):                     # 中序:左 → 根 → 右
    if n is None: return
    inorder(n.left)
    print(n.val, end=' ')
    inorder(n.right)

def postorder(n):                   # 后序:左 → 右 → 根
    if n is None: return
    postorder(n.left)
    postorder(n.right)
    print(n.val, end=' ')

三个函数唯一区别是 print 在两次递归调用的前、中、后——遍历的全部秘密。

例题 4-1 手走一棵二叉树的三种遍历
一棵 BST 形状的二叉树(内部结点 7/3/9,叶 1/6/11):

                7
              /   \
             3     9
            / \     \
           1   5    11
                 \
                  6

前序:7 3 1 5 6 9 11;中序:1 3 5 6 7 9 11;后序:1 6 5 3 11 9 7。自查:中序恰好升序,因为是 BST(§4.4)。

误区 1:把"访问"与"递归调用"的顺序搞混

打印语句在两次递归之间的位置决定遍历类型——三序唯一的区别就是这行 print 放哪。先用最小树手推一遍再对照。

4.2.2 层序遍历(用队列,呼应第3章)

层序遍历按"从上到下、每层从左到右"访问。递归天然深入、做不到逐层横推,必须用第3章的队列:根先入队,出队访问后左右子结点再入队。Python 用 collections.deque:

示例 4-3 层序遍历:deque
from collections import deque

def level_order(root):              # 层序:先进先出
    if root is None: return
    q = deque([root])
    while q:
        n = q.popleft()             # 出队
        print(n.val, end=' ')
        if n.left:  q.append(n.left)
        if n.right: q.append(n.right)

4.2.3 显式栈模拟递归(Python 简化版)

任何递归都能改写成"显式栈 + 循环"(第3章)。系统栈压"返回地址 + 局部变量",显式栈压"待处理的结点"。Python 版只收集序列不打印,print 与递归分离更接近"返回列表"的工程写法:

示例 4-4 迭代中序遍历:显式栈
def inorder_iter(root):             # 显式栈模拟递归中序
    st, cur, out = [], root, []
    while cur or st:
        while cur:                  # 1. 沿左链一路压栈
            st.append(cur)
            cur = cur.left
        cur = st.pop()              # 2. 出栈
        out.append(cur.val)         # 3. 访问发生在出栈时
        cur = cur.right             # 4. 转向右子树
    return out                      # 返回中序序列

递归中序也是"先到最左、打印、再进右子树"——迭代版只是自己压栈。递归的代价见 §4.7.1。

4.2.4 遍历应用:求高度、结点数、叶数

三个经典问题都是"后序思想":先递归算完左右子树,再组合出答案。基准情形都是 n is None 返回 0,空树基准让"单个叶结点"自然成立;写树递归先问:空结点返回什么?

示例 4-5 树高、结点数、叶数
def height(n):                      # 空树高度为 0
    if n is None: return 0
    return 1 + max(height(n.left), height(n.right))

def count_nodes(n):                 # 结点数
    if n is None: return 0
    return 1 + count_nodes(n.left) + count_nodes(n.right)

def count_leaves(n):                # 叶:左右都为空
    if n is None: return 0
    if n.left is None and n.right is None: return 1
    return count_leaves(n.left) + count_leaves(n.right)

§4.3 表达式树

4.3.1 表达式树的结构

表达式树是编译器处理算术表达式的内部表示:叶结点是操作数,内部结点是运算符,左右子树就是两个操作数——后缀式 6 5 2 3 + * + 对应:

图 4-2 后缀式 6 5 2 3 + * + 的表达式树
表达式树:叶是操作数,内部是运算符。

            +                 ← 根:最后出现的运算符
          /   \
         6     *              ← 中序恢复:(6 + (5 * (2 + 3)))
             /   \
            5     +
                /   \
               2     3        ← 叶:操作数

4.3.2 由后缀表达式构建(用栈,衔接第3章)

构建与第3章后缀求值几乎同构:遇数字建叶结点入栈;遇运算符弹出两棵子树——先弹的是右操作数——合并压回。区别只在栈里存数值还是树结点:

示例 4-6 由后缀表达式构建表达式树
class ExprNode:                     # 表达式树结点
    def __init__(self, data, left=None, right=None):
        self.data = data            # 数字或运算符
        self.left = left
        self.right = right

def build_expr_tree(post):          # post:后缀式列表
    st = []
    for t in post:
        if t.isdigit():
            st.append(ExprNode(t))  # 数字:建叶结点入栈
        else:
            r = st.pop()            # 先弹的是右操作数
            l = st.pop()
            st.append(ExprNode(t, l, r))  # 合并成父结点压回
    return st[0]                    # 栈顶即根
误区 2:左右子树接反

弹出时先弹的是右操作数。把 r 接成左子树,6 5 - 就会算成 5−6。写完用 print_infix 核对带减号的结果。

4.3.3 中序遍历恢复中缀表达式

三序遍历与三种表达式记法一一对应:前序 = 前缀式,中序 = 中缀式,后序 = 后缀式。中序遍历表达式树输出的正是人读的中缀;为优先级自洽,给每个运算符子树加括号:

示例 4-7 中序恢复中缀(带括号)
def print_infix(n):                 # 中序恢复中缀
    if n is None: return
    is_op = not n.data.isdigit()
    if is_op: print('(', end='')    # 运算符子树加括号
    print_infix(n.left)
    print(n.data, end='')
    print_infix(n.right)
    if is_op: print(')', end='')
重点:三序遍历 × 三种表达式 = 一个闭环

第3章"中缀转后缀"把 (1+2)*3 变 12+3*;本章"后缀建树 + 中序恢复"把它变回 ((1+2)*3)。三种记法、三种遍历是同一信息的三副面孔。

§4.4 二叉查找树(BST)

4.4.1 BST 性质与 contains/findMin/findMax

二叉查找树(BST)性质:每个结点的左子树所有值都小于它,右子树所有值都大于它。推论:中序遍历输出严格升序。查找 = 比较后走左或右,一路下行丢掉一半子树——二分查找的树形版,插入删除不用搬移元素:

示例 4-8 BST:contains/find_min/find_max
class Node:                         # 结点:val + 左右引用
    def __init__(self, val, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class BST:
    def __init__(self):
        self.root = None            # 对象引用,无需指针

    def contains(self, x):          # 查找:沿一条路径下行
        n = self.root
        while n:
            if x == n.val: return True
            n = n.left if x < n.val else n.right
        return False

    def find_min(self):             # 最小:一路向左
        n = self.root
        while n.left: n = n.left
        return n.val

    def find_max(self):             # 最大:一路向右
        n = self.root
        while n.right: n = n.right
        return n.val

4.4.2 插入 insert

C 的做法是"遍历到空位,改父结点指针";Python 更稳的是递归返回"新根":引用修改收拢在 return 里,父结点用返回值接住:

示例 4-9 BST 插入:递归返回新根
    def insert(self, x):
        self.root = self._insert(self.root, x)

    def _insert(self, n, x):
        if n is None: return Node(x)     # 空位:新建结点
        if x < n.val:  n.left = self._insert(n.left, x)
        elif x > n.val: n.right = self._insert(n.right, x)
        return n                         # 相等:忽略

4.4.3 删除 remove:三种情形

删除三情形:① 叶:直接删;② 单子:让唯一子结点顶替;③ 双子:用右子树的最小结点顶替被删结点,再删掉它——它大于左子树全部、小于右子树其余,且无左子树:

示例 4-10 BST 删除:三种情形
    def remove(self, x):
        self.root = self._remove(self.root, x)

    def _find_min_node(self, n):         # 子树中的最小结点
        while n.left: n = n.left
        return n

    def _remove(self, n, x):
        if n is None: return None        # 不存在,忽略
        if x < n.val:  n.left = self._remove(n.left, x)
        elif x > n.val: n.right = self._remove(n.right, x)
        else:                            # 找到 x
            if n.left is None:  return n.right   # 叶或只有右子树
            if n.right is None: return n.left    # 只有左子树
            m = self._find_min_node(n.right)     # 双子
            n.val = m.val                        # 复制数据顶替
            n.right = self._remove(n.right, m.val)  # 删掉最小结点
        return n
误区 3:双子删除的两处经典翻车

① 漏接右子树:只写 n.val = m.val 就 return n,m 还挂在右子树里——重复且泄漏,必须再递归删除 m。② 删错目标:写成 n.right = self._remove(n.right, x) 必扑空。先复制,再用 m 删右子树。

误区 4:删除后旧引用悬空

调用方若写 p = tree.root; tree.remove(x); p.val = ...——p 可能已被顶替删除,再改 p 等于改一个已脱离树的孤立结点。删除/修改容器后,旧引用一律视为失效。

4.4.4 复杂度直觉与"手写 vs 标准库"

BST 每个操作沿一条路径下行,路径长度 = 树高。随机插入时树高约 1.39 log2 n,操作平均 O(log n);数据恰好有序插入时树退化成链,查找变线性扫描。

误区 5:把"平均"当"保证"(退化链)

给 BST 喂升序序列,它长成一条只有右孩子的链,查 1 要 O(n)。这不是理论病:自增主键、日志时间戳等"按序到达"的数据都会触发。解法:① 打乱插入顺序;② 自平衡结构——AVL(§4.5)——把树高保证在 O(log n)。

Python 没有内置平衡树,"有序集合"的工程替代是 sorted list + bisect;手写 BST 只为理解原理:

示例 4-11 手写 BST 查找 vs sorted list + bisect(并排)
# 手写 BST:平均 O(log n),最坏 O(n)
tree = BST()
for x in (15, 6, 18):
    tree.insert(x)
print(tree.contains(6))              # True

# 标准库写法:sorted list + bisect 保持有序
from bisect import bisect_left, insort
lst = []
for x in (15, 6, 18):
    insort(lst, x)                   # 插入 O(n),查找 O(log n)
i = bisect_left(lst, 6)              # 二分定位
print(i < len(lst) and lst[i] == 6)  # True
C 的手写查找树Python 的手写树 + bisect
手写 Node 结构 + 递归插入/删除,还要管内存类 + 对象引用,GC 自动回收内存
有序插入退化成链,最坏 O(n)同样退化;换 AVL 或 sorted list + bisect
标准库 set/map 是红黑树,保证 O(log n)Python 无内置平衡树;dict 无序但平均 O(1)

§4.5 AVL 树

4.5.1 平衡因子与失衡类型

AVL 树是第一种自平衡 BST:每个结点的左右子树高度差至多 1。平衡因子 bf(v) = height(v.left) − height(v.right),合法值只有 −1、0、+1;插入可能把某祖先推到 ±2,用旋转扳回,四种,看失衡结点的哪个孩子更高:

图 4-3 失衡判定:四种类型
bf(v) = height(v.left) - height(v.right),合法取值只有 -1/0/1。

            k2                 ← bf = +2,失衡!
          /   \
        k1     Z
        / \
      A   k3                   ← k1 的右子树更高 → LR 型
         /  \
        B    C

LL:bf=+2 且左重;RR:bf=-2 且右重;LR:bf=+2 且右重;RL:bf=-2 且左重。

记忆法:LL 是"左左",失衡结点和高孩子都在左,一次右旋;LR 是"左右",先下后上。

4.5.2 四种旋转的实现

AVL 结点比 BST 多一个 height 字段:Node(val, height=1)。四种旋转只改引用、O(1),与 C++ 版逐行对应:

示例 4-12 AVL 四种旋转
def h(n): return n.height if n else 0

def rotate_ll(k2):                  # LL:右旋——左孩子提为根
    k1 = k2.left
    k2.left = k1.right
    k1.right = k2
    k2.height = 1 + max(h(k2.left), h(k2.right))
    k1.height = 1 + max(h(k1.left), h(k1.right))
    return k1

def rotate_rr(k1):                  # RR:左旋,镜像对称
    k2 = k1.right
    k1.right = k2.left
    k2.left = k1
    k1.height = 1 + max(h(k1.left), h(k1.right))
    k2.height = 1 + max(h(k2.left), h(k2.right))
    return k2

def rotate_lr(k3):                  # LR:先左旋左孩子,再右旋自己
    k3.left = rotate_rr(k3.left)
    return rotate_ll(k3)

def rotate_rl(k1):                  # RL:先右旋右孩子,再左旋自己
    k1.right = rotate_ll(k1.right)
    return rotate_rr(k1)
重点:旋转的口诀

单旋转(LL/RR)是"把高孩子提上来当根,自己让位,多余的一支过继"——只改三个引用,O(1);双旋转(LR/RL)是"先捋直再旋转"。旋转不破坏 BST 的大小序——中序遍历结果不变。

4.5.3 插入后的重平衡与复杂度对照

AVL 插入 = BST 插入 + 沿路径回溯:每层更新高度、检查平衡因子。插入只改变一条路径,第一个失衡点旋转一次即恢复平衡:

示例 4-13 AVL 插入:更新高度 + 失衡判定
def insert(n, x):
    if n is None: return Node(x, height=1)
    if x < n.val:  n.left = insert(n.left, x)
    elif x > n.val: n.right = insert(n.right, x)
    n.height = 1 + max(h(n.left), h(n.right))   # 更新高度
    bf = h(n.left) - h(n.right)                 # 平衡因子
    if bf > 1:                       # 左子树高:LL 或 LR
        if x < n.left.val: return rotate_ll(n)  # LL
        return rotate_lr(n)                      # LR
    if bf < -1:                      # 右子树高:RR 或 RL
        if x > n.right.val: return rotate_rr(n) # RR
        return rotate_rl(n)                      # RL
    return n                         # 本结点仍平衡

判定 LL/LR:看 x 落在失衡结点左孩子的哪一侧,x < n.left.val 是 LL,否则 LR。

例题 4-2(手走旋转):空树依次插入 3、2、1:结点 3 的 bf=2 且落在左孩子 2 的左子树 → LL,右旋:2 提为根,3 变其右孩子;再插 4、5,结点 3 的 bf=−2 → RR。最终:根 2,左 1,右 4(左 3 右 5)。

§4.6 伸展树与 B 树

4.6.1 伸展树:摊还与访问局部性

伸展树(splay tree)的动机是访问局部性:刚被访问的数据往往很快再次被访问(缓存、词频查询、符号表)。AVL 用平衡因子保证每次 O(log n),代价是代码复杂;伸展树不要平衡因子,只约定:每次访问后把该结点"伸展"到根。

结论(证明在第11章摊还分析):单次最坏 O(n),连续 m 次操作总代价 O(m log n),摊还 O(log n);反复访问的结点总停在根附近,但单次最坏延迟无法保证。

4.6.2 B 树:磁盘 IO 与"浅而宽"

B 树的动机是磁盘:磁盘随机读约 10 ms,内存访问是纳秒级,差约 10 万倍,数据库索引里决定性能的不是比较次数,而是下潜层数(= IO 次数)。BST 树高约 log2 n,107 条记录约 23 层;B 树是"M 路分支",树高降到 logM n,取 M=1000 只需 3 层——"浅而宽"把 IO 从 20 多压到 3。

结论:B 树查找/插入/删除都是 O(logM n);分裂/合并细节不展开,工程上按"一个结点装满一个磁盘块"定 M。SQLite 的 B+ 树等索引都是它的工业后代。

§4.7 工程与实践

4.7.1 递归深度限制:对象引用建树与 RecursionError

C++ 版的 §4.7 在讲 unique_ptr;Python 完全不同:对象引用 + 引用计数自动管理内存,没有泄漏与悬垂指针问题——真正的瓶颈是递归深度。每个递归调用占一个调用帧,Python 默认限制约 1000 层,退化链(树高 n)的插入、求高会直接抛 RecursionError:

示例 4-14 撞上限与迭代替代
deep = BST()
for i in range(1500):               # 退化链:树高 = 1500
    deep.insert(i)                  # _insert 递归 1500 层
# RecursionError: maximum recursion depth exceeded

# 治本:迭代版中序遍历,不占递归帧
def inorder_iter(root):
    st, cur, out = [], root, []
    while cur or st:
        while cur:
            st.append(cur)
            cur = cur.left
        cur = st.pop()
        out.append(cur.val)
        cur = cur.right
    return out
误区 6:调大递归限制治标不治本

sys.setrecursionlimit(1000000) 只是把上限抬高——真到百万层,Python 解释器本身(C 栈)也扛不住,可能直接崩溃而不是抛异常。正确姿势:① 深度可控(平衡树,树高 O(log n))时放心用递归;② 深度可能失控时写迭代版(§4.2.3 的显式栈)。先想清楚"递归深度 = 树高",再决定写递归还是迭代。

C 的 malloc/free 树Python 的对象引用树

销毁整树要手写递归 delete,深树爆栈无手动销毁;但递归深度约 1000 层,深树用迭代
释放后指针仍存在,悬垂是未定义行为引用天然安全;环形引用由 GC 兜底

4.7.2 标准库对照:Python 没有内置平衡树

C++ 的 std::set/std::map 底层是红黑树;Python 的 dict/set 是散列表,无序但平均 O(1)。有序场景的工程惯例是 sorted list + bisect(插入 O(n)、查找 O(log n));数据量大、要求更高的替代品(sortedcontainers 等)第12章细讲。先记住选型口诀:只要"字典序/范围查询"就绕不开有序结构;只查存在与否,用 dict/set 更快:

示例 4-15 dict 词频统计 + 字典序输出
words = ['cat', 'dog', 'cat', 'bird']
freq = {}
for w in words:
    freq[w] = freq.get(w, 0) + 1    # 无序:平均 O(1)

# 要字典序输出:按 key 排序(工程惯例)
for w, c in sorted(freq.items()):
    print(w, c)                     # bird 1 / cat 2 / dog 1

# 查找频次:O(1)
print(freq.get('cat', 0))           # 2

3. 后缀式 6 5 2 - 3 * + 的表达式树,中序恢复(带括号)是什么?
参考答案

构建:6、5、2 入栈;- 弹 2、5 得 (5−2);3 入栈;* 得 (5−2)*3;+ 得 6+((5−2)*3)。先弹的是右操作数,故是 5−2 而非 2−5。

右子树最小结点 m 大于左子树全部、小于右子树其余,顶替后性质不变;且 m 没有左子树,删除退化为单子/叶情形。取左子树最大结点也可行。

# lab4.py —— 单词频次统计器(BST 实现)(第一段:结点与核心操作)
import sys

class Node:                       # 单词 + 频次 + 左右子树
    def __init__(self, word, count=1):
        self.word, self.count = word, count
        self.left = self.right = None

class WordBST:
    def __init__(self):
        self.root = None

    def insert(self, w):
        self.root = self._insert(self.root, w)

    def _insert(self, n, w):
        if n is None:
            return Node(w)          # 空位:新建结点
        if w < n.word:
            n.left = self._insert(n.left, w)
        elif w > n.word:
            n.right = self._insert(n.right, w)
        else:
            n.count += 1            # 已存在:频次 +1
        return n

    def find(self, w):              # 查找频次,不存在返回 0
        n = self.root
        while n:
            if w == n.word:
                return n.count
            n = n.left if w < n.word else n.right
        return 0

    def remove(self, w):
        self.root = self._remove(self.root, w)

    def _find_min_node(self, n):    # 右子树最小结点
        while n.left:
            n = n.left
        return n

    def _remove(self, n, w):
        if n is None:
            return None             # 单词不存在,忽略
        if w < n.word:
            n.left = self._remove(n.left, w)
        elif w > n.word:
            n.right = self._remove(n.right, w)
        else:                       # 找到目标结点
            if n.left is None:
                return n.right      # 叶或只有右子树
            if n.right is None:
                return n.left       # 只有左子树
            m = self._find_min_node(n.right)   # 双子:取右子树最小
            n.word = m.word         # 复制数据顶替
            n.count = m.count
            n.right = self._remove(n.right, m.word)
        return n
# (第二段:中序、树高与平衡检查——类方法,复用示例 4-5 思路)
    def inorder(self):              # 中序 = 字典序
        self._inorder(self.root)

    def _inorder(self, n):
        if n is None:
            return
        self._inorder(n.left)
        print(n.word + '\t' + str(n.count))
        self._inorder(n.right)

    def height(self):               # 空树高度为 0
        return self._height(self.root)

    def _height(self, n):
        if n is None:
            return 0
        return 1 + max(self._height(n.left), self._height(n.right))

    def is_balanced(self):          # 自底向上检查
        _, ok = self._check(self.root)
        return ok

    def _check(self, n):            # 返回(高度, 是否平衡)
        if n is None:
            return 0, True
        hl, bl = self._check(n.left)
        hr, br = self._check(n.right)
        return 1 + max(hl, hr), bl and br and abs(hl - hr) <= 1
# (第三段:主程序——分词、统计、输出)
def main():
    print("单词频次统计器(BST 实现)——输入英文文本,空行结束:")
    lines = []
    for line in sys.stdin:
        if line.strip() == '':
            break
        lines.append(line)
    text = '\n'.join(lines)

    tree = WordBST()
    word = ''
    for ch in text:                 # 任务 1:分词转小写
        if ch.isalpha():
            word += ch.lower()
        elif word:
            tree.insert(word)       # 任务 2:插入统计
            word = ''
    if word:
        tree.insert(word)

    print("\n--- 任务 3:中序遍历输出词频表(字典序)---")
    tree.inorder()

    print("\n--- 任务 4:查找频次 ---")
    for w in ('the', 'dog', 'hello'):
        print("查找 '%s': 频次 = %d" % (w, tree.find(w)))

    print("\n删除 'dog' 后重新遍历:")
    tree.remove('dog')
    print("删除后 'dog' 频次 = %d(应为 0)" % tree.find('dog'))
    tree.inorder()

    print("\n--- 任务 5(加分):树高与平衡检查 ---")
    print("树高 = %d, 是否平衡 = %s" % (tree.height(),
          ('是' if tree.is_balanced() else '否')))

if __name__ == '__main__':
    main()
