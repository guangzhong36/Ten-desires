§10.1 贪心:活动安排与哈夫曼编码

10.1.1 贪心思想:每步取局部最优

贪心(greedy) 一句话:每一步选"当前看起来最好"的选择,希望最终全局最优。它不回头、不后悔,因此要求"无后效性"。经典案例:找零钱、活动安排、哈夫曼。注意:贪心正确性必须逐题验证,没有通用模板——这是它最大的坑(误区 1)。

10.1.2 活动安排问题

会议室只有一个,每个活动有开始与结束时间,同一时刻只能进行一个,问最多能安排几个?策略:按结束时间最早排序,依次选不冲突的活动——最早结束优先。例:10 个活动排序后扫描,选中 (1,4)、(5,7)、(8,11),恰为最优。

示例 10-1 活动安排:最早结束优先
// 活动安排:按结束时间升序,依次选不冲突的活动
struct Act { int start, end; };          // 开始、结束时间
vector<Act> activitySelect(vector<Act> acts) {
    sort(acts.begin(), acts.end(),       // 贪心策略:最早结束优先
         [](const Act& a, const Act& b) { return a.end < b.end; });
    vector<Act> res;
    int lastEnd = -1;                    // 上一个选中活动的结束时间
    for (const Act& a : acts) {
        if (a.start >= lastEnd) {        // 不冲突:直接选
            res.push_back(a);
            lastEnd = a.end;
        }
    }
    return res;
}

10.1.3 为什么"最早结束"是对的

为什么不用"最早开始"或"持续时间最短"?直觉:结束得越早,留给后面的空闲越多。严格证明叫交换论证(教材给出):把第一个活动换成"结束最早的活动"不会变差——它结束得不晚,后面所有活动仍放得下;逐步替换即可。注意直觉不是证明,后文有反例。

10.1.4 任务调度简介

同族另一个贪心:单机任务调度——已知各任务处理时间,使平均完成时间最小。策略:最短处理时间优先(SJF):短任务先完成,大家等待的总时间最小;交换论证同样成立。这是操作系统"短作业优先"的原型。复杂度 O(n log n)。

10.1.5 哈夫曼编码:前缀码与二叉堆

变长编码:高频字符用短码、低频用长码。但变长有歧义:a=0, b=01 时,01 是 a+b 还是 b?靠前缀码解决:任何编码都不是另一个编码的前缀。哈夫曼算法构造平均码长最短的前缀码:每次合并频次最小的两棵(频次相加),直到剩一棵;频次越低,离根越远、码越长。取最小用第6章二叉堆:

示例 10-2 哈夫曼编码:最小堆建树与编码
// 哈夫曼结点:叶存字符,内部结点 ch 为 '\0'
struct HNode {
    char ch;
    int freq;
    HNode *left, *right;
    HNode(char c, int f)
        : ch(c), freq(f), left(nullptr), right(nullptr) {}
    bool isLeaf() const { return ch != '\0'; }
};
// 比较器:频次小者优先(默认大顶堆,取反)
struct Cmp {
    bool operator()(const HNode* a, const HNode* b) const {
        return a->freq > b->freq;
    }
};
// 建树:每次合并频次最小的两棵
HNode* buildHuffman(const map<char, int>& freq) {
    priority_queue<HNode*, vector<HNode*>, Cmp> pq;
    for (const auto& p : freq) pq.push(new HNode(p.first, p.second));
    while (pq.size() > 1) {
        HNode* a = pq.top(); pq.pop();      // 取两个最小频次
        HNode* b = pq.top(); pq.pop();
        HNode* p = new HNode('\0', a->freq + b->freq);   // 合并
        p->left = a; p->right = b;
        pq.push(p);
    }
    return pq.top();                        // 只剩根
}
// DFS 生成编码:左 0 右 1,叶即编码
void genCodes(HNode* r, string path, map<char, string>& codes) {
    if (r->isLeaf()) { codes[r->ch] = path; return; }
    genCodes(r->left,  path + "0", codes);
    genCodes(r->right, path + "1", codes);
}
C 的写法(手写最小堆)C++ 的写法(priority_queue)
每次取最小线性扫描,建树 O(n2)堆取最小 O(log n),建树 O(n log n)
数组 + 上滤下滤手写约 60 行priority_queue + 自定义比较器几行
比较逻辑写死在代码里比较器是模板参数,随意更换
结点手动 free,易泄漏可配合 unique_ptr 自动释放(第4章)

重点:为什么前缀码无歧义。哈夫曼编码是树上的叶编码:字符对应叶,编码是根到叶的路径。根到叶的路径不经过另一棵叶,任意两叶编码互不为前缀——解码器从左到右扫描,到叶就输出一个字符,绝不卡壳。字符必须全放叶上,放进内部结点就产生歧义。

误区 1:贪心不是万能——硬币反例

硬币面值 {1, 3, 4} 凑 6 元。"尽量用大面值"给出 4+1+1 共 3 枚;最优是 3+3 共 2 枚。每步局部最优(先用 4 元)恰恰堵死了全局最优(两个 3 元)。贪心无通用证明:先想反例,再考虑交换论证;第9章 Dijkstra、Kruskal 敢用贪心,是因有严格证明。

§10.2 分治:最近点对与分治三要素

10.2.1 回顾:分治三要素与复杂度

分治在第2、7章反复出场(最大子序列和、归并、快排),归纳三要素:分(Divide)——切成更小的子问题;治(Conquer)——递归求解;合(Combine)——合并答案。归并与最大子序列和都是 T(n) = 2T(n/2) + O(n):每层 O(n)、共 log2 n 层,总计 O(n log n);另一形态 T(n) = T(n/2) + O(1) → O(log n)(二分)。遇到 T(n) = aT(n/b) + f(n),画递归树看每层总代价。

记号说明(沿用第2章)

递推式用行内代码:T(n) = 2T(n/2) + O(n) 表示"两个规模 n/2 的子问题 + 线性合并";n2、2n、log2 n 同第2章;"平均复杂度"指输入等概率分布下的期望值。

10.2.2 最近点对:思想与结论

平面上 n 个点,求距离最近的一对。暴力两两枚举 O(n2)。分治:① 分:按 x 排序从中间切两半;② 治:递归求两半各自最小距离得 d;③ 合(精髓):跨中线的点对只需检查"距中线 d 以内"的条带——按 y 排序后每点至多与后面 7 个点比较(d×2d 矩形内至多塞下常数个点,证明见教材)。总复杂度 O(n log n)。

示例 10-3 最近点对:分治骨架
struct Point { double x, y; };  // 平面点
double dist(const Point& a, const Point& b) {
    double dx = a.x - b.x, dy = a.y - b.y;
    return sqrt(dx * dx + dy * dy);
}
// 最近点对:pts 已按 x 升序;返回最小距离
double closestPair(vector<Point> pts) {
    int n = int(pts.size());
    if (n <= 3) {                                    // 基准情形:暴力
        double d = 1e18;
        for (int i = 0; i < n; ++i)
            for (int j = i + 1; j < n; ++j)
                d = min(d, dist(pts[i], pts[j]));
        return d;
    }
    int mid = n / 2;
    double midX = pts[mid].x;
    double d = min(
        closestPair(vector<Point>(pts.begin(), pts.begin() + mid)),
        closestPair(vector<Point>(pts.begin() + mid, pts.end())));
    // 合:收集距中线 < d 的点,按 y 排序,每点至多查 7 个
    vector<Point> strip;
    for (const Point& p : pts)
        if (fabs(p.x - midX) < d) strip.push_back(p);
    sort(strip.begin(), strip.end(),
         [](const Point& a, const Point& b) { return a.y < b.y; });
    for (size_t i = 0; i < strip.size(); ++i)
        for (size_t j = i + 1; j < strip.size() && j <= i + 7; ++j)
            d = min(d, dist(strip[i], strip[j]));
    return d;
}

§10.3 动态规划:重叠子问题与状态设计

10.3.1 分治与 DP:重叠子问题

分治假设子问题互不相交。但递归分解常产生大量相同子问题:fib(5) 要算 fib(4) 与 fib(3),fib(4) 又要算 fib(3)——fib(3) 被重复算。动态规划(DP):把子问题答案存进表格,用到查表,每个子问题只算一次。分治靠递归树,DP 靠表格,这是本质区别。

10.3.2 斐波那契:记忆化与自底向上

第1章的朴素递归是 O(2n),fib(50) 算到地老天荒。两种救法:记忆化(自顶向下:递归 + 查表)与自底向上(从 fib(0) 按序填表),都做到 O(n);后者省掉递归开销,工程首选。

示例 10-4 斐波那契三版
// 版本一:朴素递归 O(2^n)(第1章)
long long fibRec(int n) { return n <= 1 ? n : fibRec(n - 1) + fibRec(n - 2); }
// 版本二:记忆化(自顶向下):先查表再递归
long long fibMemo(int n, vector<long long>& memo) {
    if (memo[n] != -1) return memo[n];
    return memo[n] = fibMemo(n - 1, memo) + fibMemo(n - 2, memo);
}
// 版本三:自底向上:从小到大填表,O(n)
long long fibIter(int n) {
    if (n <= 1) return n;
    long long a = 0, b = 1;
    for (int i = 2; i <= n; ++i) { long long t = a + b; a = b; b = t; }
    return b;
}

10.3.3 最长公共子序列 LCS

子序列:按顺序挑出(可跳着)的字符序列。LCS:两字符串的最长公共子序列。状态:dp[i][j] = s1 前 i 个与 s2 前 j 个的 LCS 长度。转移:① 字符相等 dp[i][j] = dp[i−1][j−1] + 1;② 否则取 max(dp[i−1][j], dp[i][j−1])。填完表从右下角沿来路逆推还原出具体 LCS——方案回溯是 DP 常客。例:ABCBDAB 与 BDCABA 得长度 4,LCS 为 "BCBA"(不唯一)。

示例 10-5 LCS:DP 表构造与回溯
// 返回 LCS 长度并填好 dp 表
int buildLCSTable(const string& s1, const string& s2,
                  vector<vector<int>>& dp) {
    int m = int(s1.size()), n = int(s2.size());
    dp.assign(m + 1, vector<int>(n + 1, 0));
    for (int i = 1; i <= m; ++i)
        for (int j = 1; j <= n; ++j) {
            if (s1[i - 1] == s2[j - 1])
                dp[i][j] = dp[i - 1][j - 1] + 1;          // 相等:左上+1
            else
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);  // 不等:取较大
        }
    return dp[m][n];
}
// 回溯:从右下角沿来路逆推,收集 LCS 字符
string traceLCS(const string& s1, const string& s2,
                const vector<vector<int>>& dp) {
    string res;
    int i = int(s1.size()), j = int(s2.size());
    while (i > 0 && j > 0) {
        if (s1[i - 1] == s2[j - 1]) {           // 相等:这个字符属于 LCS
            res += s1[i - 1];
            --i; --j;
        } else if (dp[i - 1][j] >= dp[i][j - 1])
            --i;                                 // 从上方来
        else
            --j;                                 // 从左方来
    }
    reverse(res.begin(), res.end());
    return res;
}

10.3.4 0-1 背包:二维表与一维优化

0-1 背包:n 件物品,第 i 件重 w[i]、值 v[i],容量 W,每件要么整放要么不放,求最大总价值。状态:dp[i][c] = 只用前 i 件、容量 c 的最大价值。转移:放第 i 件得 dp[i-1][c-w[i-1]] + v[i-1],不放得 dp[i-1][c],取最大。二维表 O(nW) 时间空间;一维滚动数组把空间压到 O(W),代价是容量必须逆序循环——正序时 dp[c−w] 已被本轮更新,同一件被放多次(误区 2)。

示例 10-6 0-1 背包:二维与一维
// 二维版:dp[i][c] = 只用前 i 件、容量 c 的最大价值
int knap2D(const vector<int>& w, const vector<int>& v, int W) {
    int n = int(w.size());
    vector<vector<int>> dp(n + 1, vector<int>(W + 1, 0));
    for (int i = 1; i <= n; ++i)
        for (int c = 1; c <= W; ++c)
            dp[i][c] = (c >= w[i - 1])
                ? max(dp[i - 1][c], dp[i - 1][c - w[i - 1]] + v[i - 1])
                : dp[i - 1][c];
    return dp[n][W];
}
// 一维版:滚动数组。容量必须逆序!正序变成完全背包
int knap1D(const vector<int>& w, const vector<int>& v, int W) {
    vector<int> dp(W + 1, 0);
    for (int i = 0; i < int(w.size()); ++i)
        for (int c = W; c >= w[i]; --c)       // 逆序是关键
            dp[c] = max(dp[c], dp[c - w[i]] + v[i]);
    return dp[W];
}
C 的写法(手工二维数组)C++ 的写法(vector)
malloc 每行再逐行 free,易错vector<vector<int>> dp(n+1, vector<int>(W+1, 0)) 自动清零释放
越界读写是未定义行为dp.at(i).at(c) 越界抛异常,调试友好
维度要手把手传参dp.size() 自带维度,范围 for 可遍历
换一维滚动数组要重写全部下标两版结构一致,只差循环方向
误区 2:一维背包的容量循环写成正序

一维版要求 dp[c - w[i]] 还是"上一轮"的值。逆序保证更新 dp[c] 时 dp[c−w[i]] 尚未被本轮更新;正序则可能已被更新,第 i 件被用多次——正是完全背包的转移式。口诀:01 背包逆序,完全背包正序。验证:小样例手工跑,或与二维版对拍(实验任务 3)。

重点:DP 解题五步(全章最重要的清单)

① 定义状态:dp 下标代表什么?要完整描述局面且不冗余;② 写转移方程:当前状态由哪些更小的状态转移来?③ 定初值与边界:首行首列、空输入、容量 0 的答案?④ 定计算顺序:依赖项先算好(通常从小到大);⑤ 方案回溯:需要方案时记录选择或从终态逆推。

§10.4 随机化:洗牌与第 k 小

10.4.1 Fisher-Yates 洗牌

把数组随机打乱,朴素做法(任意位置交换)分布不均匀。Fisher-Yates 的关键:第 i 步只与 [0, i] 中的随机位置交换(从后往前),交换后位置 i 被锁定。共 n! 种等可能交换序列,与排列一一对应。std::shuffle 就是它。

示例 10-7 Fisher-Yates 与 std::shuffle 并排
// 手写 Fisher-Yates:从后往前,每个位置与 [0, i] 中随机位置交换
void fisherYates(vector<int>& a, mt19937& rng) {
    for (int i = int(a.size()) - 1; i >= 1; --i) {
        uniform_int_distribution<int> dist(0, i);   // 关键:上界是 i!
        swap(a[i], a[dist(rng)]);
    }
}
// 标准库写法:一行完成,内部就是 Fisher-Yates
void shuffleStd(vector<int>& a, mt19937& rng) {
    shuffle(a.begin(), a.end(), rng);
}
误区 3:洗牌上界取 [0, n−1]

若每步从 n 个位置随机挑,共 nn 种等可能序列,排列只有 n! 种——nn 不被 n! 整除,必有不均:如 n=3 时 (1,2,3) 概率 2/9。Fisher-Yates 每步可选数递减(1·2·…·n = n!),一一对应。实证:洗 10 万次统计排列分布。

10.4.2 quickselect:求第 k 小

求第 k 小(0 基)。排序后取第 k 位要 O(n log n)。quickselect 复用第7章快排的分割(partition):枢轴被放到最终位置 p;p == k 直接返回,否则只递归"包含第 k 小"的那一侧。期望代价 n + n/2 + n/4 + … = 2n,平均 O(n);最坏(每次切最边上)O(n2)。

示例 10-8 quickselect 与 std::nth_element 对照
// 快排的分割:把枢轴放到最终位置,返回其下标
int partition(vector<int>& a, int lo, int hi) {
    int pivot = a[hi];                   // 简化:取末元素做枢轴
    int i = lo;
    for (int j = lo; j < hi; ++j)
        if (a[j] < pivot) swap(a[i++], a[j]);
    swap(a[i], a[hi]);
    return i;
}
// 第 k 小(0 基):分割后只递归"包含第 k 小"的那一侧
int quickSelect(vector<int>& a, int lo, int hi, int k) {
    int p = partition(a, lo, hi);
    if (p == k) return a[k];
    if (p > k) return quickSelect(a, lo, p - 1, k);
    return quickSelect(a, p + 1, hi, k);
}
// 标准库对照:nth_element 后第 k 位即答案(平均 O(n))

10.4.3 随机数:从 C 的 rand() 到现代随机库

C 的 rand()/srand() 三个硬伤:① 周期短(约 231);② rand() % n 概率不均——n 不整除 RAND_MAX 时余数偏斜,低位周期短;③ 全局状态,线程不安全、不可复制。C++ <random> 拆成两层:引擎(mt19937,周期 219937−1)产生原始随机位;分布(uniform_int_distribution)映射成均匀整数。种子固定则序列可复现,是复现性的基石;引擎与分布各建一次复用,勿在循环里反复构造。

C 的写法(rand 家族)C++ 的写法(<random> 家族)
srand(time(NULL)); rand();mt19937 rng(seed); 引擎与分布分离
rand() % n 概率不均uniform_int_distribution<int> d(0, n-1) 均匀分布
全局状态,线程不安全,不可复制引擎是普通对象,可复制、可传参、可并发
周期约 231,质量差mt19937 周期 219937−1,通过统计检验
洗牌/抽样要自己写std::shuffle / std::nth_element 一行完成

10.4.4 随机算法的工程观

quickselect 平均 O(n)、最坏 O(n2)——"数学概率上快"的含义:把最坏情形的概率压到工程上可忽略。随机选枢轴后,能触发最坏的输入几乎无法被构造;对单次最坏延迟有硬性要求(实时系统)则改用确定性算法。

§10.5 回溯:选择-递归-撤销

10.5.1 回溯模板:选择-递归-撤销

当搜索空间是"一步步做决定"的结构时,回溯(backtracking) 是穷举的优雅写法:状态树上深度优先,核心三行——① 选择:决定写进状态;② 递归:进入下一层;③ 撤销:恢复状态,尝试下一个选择。撤销是灵魂,忘了它状态被污染。回溯的本质是带剪枝的深度优先穷举:排列空间 n!,子集空间 2n;八皇后不剪枝要试 64 选 8,剪枝后只访问约 1.5 万结点。剪枝两类:可行性剪枝(不可能通向合法解)与最优性剪枝(不可能优于已知最好解)——回溯"慢但保证对",贪心"快但可能错"。C++ 里递归用 std::function 包装的 lambda,见示例 10-9。

10.5.2 八皇后:完整实现

在 n×n 棋盘放 n 个皇后,任意两个不能同行、同列、同对角线。暴力枚举 C(64,8) 是天文数字;回溯逐行放皇后,O(1) 冲突检查:列 col[c];主对角线 d1[row+c](同一主对角线上 row+c 相同);副对角线 d2[row−c+n−1](row−c 相同,加 n−1 防负下标)。放不下就回退换列——"回溯"由此得名。

示例 10-9 八皇后:冲突检查与回调
// 通用回溯:每找到一个完整解,调用回调 visit(第7章函数指针的升级)
void nQueens(int row, vector<int>& pos, vector<bool>& col,
             vector<bool>& d1, vector<bool>& d2,
             const function<void(const vector<int>&)>& visit) {
    int n = int(pos.size());
    if (row == n) { visit(pos); return; }                 // 找到完整解
    for (int c = 0; c < n; ++c) {
        if (col[c] || d1[row + c] || d2[row - c + n - 1])
            continue;                                     // 冲突剪枝
        pos[row] = c;
        col[c] = d1[row + c] = d2[row - c + n - 1] = true;   // 选择
        nQueens(row + 1, pos, col, d1, d2, visit);           // 递归
        col[c] = d1[row + c] = d2[row - c + n - 1] = false;  // 撤销
    }
}
// 调用方:lambda 回调负责"计数与收集前 3 个解"
long long cnt = 0;
vector<vector<int>> first3;
vector<int> pos(8);
vector<bool> col(8), d1(15), d2(15);
nQueens(0, pos, col, d1, d2, [&](const vector<int>& sol) {
    ++cnt;
    if (first3.size() < 3) first3.push_back(sol);
});
// 结果:cnt == 92;前 3 解(1 基):(1,5,8,6,3,7,2,4)、(1,6,8,3,7,4,2,5)、(1,7,4,6,8,2,5,3)

10.5.3 子集和问题

给定正整数集合与 target,能否选出若干元素恰好和为 target?每件"选/不选"两个分支,走到叶判断命中。加可行性剪枝:已超 target 直接剪掉;总和都不够则不进搜索。子集和没有贪心可依赖(硬币反例同款),只能搜索——这就是范式选型的意义。

10.6.2 选型决策

  • 先看规模:n ≤ 20 → 回溯;n 达 106 → 多项式算法
  • 有贪心猜想?策略可构造且反例想不出 → 试贪心并证明;有反例 → 放弃
  • 能切成独立子问题?左右互不影响 → 分治
  • 有重复子问题?→ DP:定义状态、写转移、填表
  • 都不行?→ 回溯 + 剪枝,或近似/启发式

10.6.3 什么时候"想不出多项式算法":NP 问题的一句话

旅行商、哈密顿回路等问题至今没人找到多项式时间算法,普遍相信不存在——通常称 NP 难。遇到它们,心态不是"我再想想",而是:规模小用回溯 + 剪枝,规模大用近似或启发式,并明确告诉用户这是近似解。

§10.7 工程实践:状态检查、剪枝与随机化测试

10.7.1 DP 状态设计检查清单

  • 状态参数能否完整描述"当前局面"?少一个参数转移就丢信息
  • 转移方程引用的状态都"更小"吗?(防循环依赖)
  • 初始值与边界是否齐全?(首行首列、空输入、容量 0)
  • 计算顺序是否保证依赖项先算好?(背包容量、LCS 行列)
  • 空间能否优化?二维表能否滚成一维?
  • 需要输出方案吗?需要就保留完整表或记录选择

10.7.2 回溯剪枝的顺序

剪枝顺序影响常数:① 可行性剪枝放最前(冲突检查、超目标)——砍掉的子树最多;② 对称性剪枝(八皇后旋转/镜像可省约 7/8 搜索,选做);③ 最优性剪枝最后做(求最优解时用)。优先搜索分支更少的方向(如子集和先放大元素),也能显著加速。

10.7.3 随机化在测试中的应用

两个利器:① 随机数据 + 对拍——用 mt19937 生成随机小样例,把"手写实现"与"暴力实现"逐一比对,十万个随机样例比十个手写边界更早暴露 bug(实验任务 3);② 固定种子——回归可复现,换种子扩覆盖。

自测题

1. 活动安排为什么按"结束时间最早"贪心?按"开始时间最早"行吗?请举反例。
参考答案

结束得越早,给后面留下的时间越多;交换论证保证任何最优解都能换成贪心解。按"最早开始"不行:活动 A(1,10) 霸占全天,(2,3)(4,5)(6,7) 全被挡住——贪心得 1 个,最优 3 个。

2. 面值 {1, 3, 4} 凑 6 元,贪心给出什么?最优是什么?说明了什么?
参考答案

贪心 4+1+1 共 3 枚,最优 3+3 共 2 枚。局部最优 ≠ 全局最优:先用 4 元堵死了两个 3 元。贪心正确性必须逐题验证;人民币面值贪心成立,是"设计面值"的结果。

3. 分治与动态规划的本质区别是什么?各举一个代表问题。
参考答案

分治的子问题互不相交(归并左半右半无重叠),复杂度来自递归树每层合并代价;DP 的子问题大量重叠(fib(3) 被重复计算),复杂度来自"每个状态只算一次"。代表:分治——归并;DP——LCS、0-1 背包。

4. 0-1 背包的一维滚动数组为什么必须逆序?正序会怎样?
参考答案

逆序保证更新 dp[c] 时 dp[c−w[i]] 还是"没考虑第 i 件"的旧值;正序时它可能已被本轮更新,同一件物品被用多次,转移式变成完全背包。口诀:01 背包逆序,完全背包正序。验证:与二维版对拍(实验任务 3)。

5. Fisher-Yates 每步的随机上界为什么必须是 i?取 [0, n−1] 会怎样?
参考答案

Fisher-Yates 每步可选数递减,共 n! 种等可能交换序列,与排列一一对应,保证均匀。若每步从 n 个位置挑,共 nn 种序列而排列只有 n! 种,nn 不被 n! 整除,必然不均(n=3 时 (1,2,3) 概率 2/9)。实证:洗 10 万次统计分布。

#include <algorithm>
#include <chrono>
#include <functional>
#include <iostream>
#include <random>
#include <vector>
using namespace std;
using Clock = chrono::steady_clock;
// 任务 1a:二维 DP;返回 {价值, 方案下标}
pair<int, vector<int>> knap2D(int n, int W, const vector<int>& w,
                              const vector<int>& v) {
    vector<vector<int>> dp(n + 1, vector<int>(W + 1, 0));
    for (int i = 1; i <= n; ++i)
        for (int c = 1; c <= W; ++c)
            dp[i][c] = (c >= w[i - 1])
                ? max(dp[i - 1][c], dp[i - 1][c - w[i - 1]] + v[i - 1])
                : dp[i - 1][c];
    vector<int> chosen;                       // 回溯选取方案
    for (int i = n, c = W; i >= 1; --i)
        if (dp[i][c] != dp[i - 1][c]) { chosen.push_back(i - 1); c -= w[i - 1]; }
    reverse(chosen.begin(), chosen.end());
    return {dp[n][W], chosen};
}
// 任务 1b:一维滚动数组(容量必须逆序!)
pair<int, vector<int>> knap1D(int n, int W, const vector<int>& w,
                              const vector<int>& v) {
    vector<int> dp(W + 1, 0);
    vector<vector<char>> pick(n, vector<char>(W + 1, 0));
    for (int i = 0; i < n; ++i)
        for (int c = W; c >= w[i]; --c) {
            int t = dp[c - w[i]] + v[i];
            if (t > dp[c]) { dp[c] = t; pick[i][c] = 1; }
        }
    vector<int> chosen;
    for (int i = n - 1, c = W; i >= 0; --i)
        if (pick[i][c]) { chosen.push_back(i); c -= w[i]; }
    reverse(chosen.begin(), chosen.end());
    return {dp[W], chosen};
}
