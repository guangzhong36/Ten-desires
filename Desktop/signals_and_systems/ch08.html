全章核心结论一句话:通信 = 用"乘载波"把低频信号搬到高频信道去旅行,再用"乘载波 + 低通滤波"把它接回家。第4章的频移性质是全部戏法的来源。

§8.1 幅度调制:给信号"装上翅膀"

直觉先行:为什么要调制?

人声的频率只有几百赫兹,而天线要高效辐射电磁波,尺寸须与波长同量级——直接发射 300Hz 的声音需要 250 公里长的天线!另外,低频段信道拥挤且易受干扰。办法:把低频信息"驮"在高频载波 \(\cos\omega_c t\) 上发射。调制不创造信息,只是给信息换一个适合旅行的"交通工具"。

抑制载波双边带(DSB-SC)调制:\(y(t)=x(t)\cos\omega_c t\)。取傅里叶变换:

DSB-SC 调制的频谱 \[ Y(j\omega) = \frac{1}{2}X\big(j(\omega-\omega_c)\big) + \frac{1}{2}X\big(j(\omega+\omega_c)\big) \]

0 基础解读:基带频谱被"复印"两份:一份搬到 \(+\omega_c\),一份搬到 \(-\omega_c\),幅度各减半。若基带带宽为 \(\omega_M\),已调信号带宽为 \(2\omega_M\)(双边带名称的由来)。名字"抑制载波"指载波本身不出现(\(x(t)\) 均值为零时频谱里没有载波谱线)。

图 8-1 调制的频域过程:(a) 基带三角谱;(b) 载波在 ±ωc 的两根谱线;(c) 频域卷积后,基带谱整体搬移到 ±ωc 两侧,幅度减半
例题 8.1 调制频谱计算

\(x(t)=\cos(2\pi\cdot10^3 t)\)(1kHz 单音)与载波 \(\cos(2\pi\cdot10^6 t)\)(1MHz)相乘,求已调信号的频谱与带宽。

  1. 基带谱:两根谱线 \(\pi[\delta(\omega-2000\pi)+\delta(\omega+2000\pi)]\)。
  2. 与载波谱(\(\pm 2\pi\times10^6\) 处的 \(\pi\) 冲激)做频域卷积,得四根谱线。
  3. 结果:\(y(t)=\dfrac{1}{2}\cos(2\pi\cdot999\times10^3 t)+\dfrac{1}{2}\cos(2\pi\cdot1001\times10^3 t)\)——搬出 999kHz 与 1001kHz 两个边频,载波频率 1MHz 处没有分量(被抑制)。
  4. 带宽:1001−999=2kHz,恰为基带带宽的两倍。

§8.2 同步解调:把信号"接回家"

直觉先行:解调 = 再乘一次 + 洗掉高频

接收端再乘同一个载波:\(y(t)\cos\omega_c t = x(t)\cos^2\omega_c t = \dfrac{x(t)}{2}+\dfrac{x(t)}{2}\cos2\omega_c t\)。第一项就是原信号的一半,第二项被搬到了 \(2\omega_c\) 附近——用低通滤波器一"洗",高频部分冲走,基带部分留下。调制是"搬上去",解调是"再搬一次+低通"。

同步解调链路 \[ x(t)\cos\omega_c t \xrightarrow{\;\times\cos\omega_c t\;} \frac{x(t)}{2} + \frac{x(t)}{2}\cos 2\omega_c t \xrightarrow{\;\text{低通}\;(\omega_{co}\in[\omega_M,\;2\omega_c-\omega_M])\;} \frac{x(t)}{2} \]
图 8-2 同步解调的频域过程:(a) 已调谱;(b) 再乘载波后,基带谱回到原点(幅度 1/2),另有两份副本跑到 ±2ωc;(c) 低通滤波后恢复基带谱
例题 8.2 低通滤波器的截止频率怎么选?

基带带宽 \(\omega_M=2\pi\times4\) kHz,载波 \(\omega_c=2\pi\times100\) kHz。求解调低通滤波器的合理截止频率。

  1. 再乘载波后:基带成分在 \(|\omega|<\omega_M\),高频副本在 \(\omega=2\omega_c\pm\omega_M\) 附近。
  2. 低通截止频率须满足:\(\omega_M<\omega_{co}<2\omega_c-\omega_M\)——放行基带、挡住 \(2\omega_c\) 副本。
  3. 代入:\(\omega_{co}\) 取 4kHz 到 196kHz 之间任何值都行,工程上常取 8–10kHz。
  4. 前提:\(\omega_c>\omega_M\)(载波高于基带带宽,否则频谱重叠,低通无法分离)。
常见误区 1:解调用的载波不必与原载波严格同步

错。同步解调的灵魂就在"同步"二字。若本地载波为 \(\cos(\omega_c t+\phi)\),解调输出为 \(\dfrac{x(t)}{2}\cos\phi\)——相位偏差 \(\phi\) 直接衰减信号(\(\phi=90°\) 时输出为零!);若本地频率偏差 \(\Delta\omega\),输出为 \(\dfrac{x(t)}{2}\cos(\Delta\omega\, t)\),信号被一个慢变化的拍频"扭曲"。工程上靠锁相环(PLL)从接收信号中恢复载波。

§8.3 含载波的 AM 与包络检波

DSB-SC 要求接收端有精确同步的本地载波,电路复杂。解决办法:发射时把载波本身也发过去:

含载波 AM \[ y(t) = \big[1 + m\,x(t)\big]\cos\omega_c t, \qquad 0

接收端只需最简单的包络检波(二极管+电容,跟随波形轮廓)即可解调——上世纪广播收音机的核心就便宜在这里。代价:载波消耗大量发射功率(信息其实只在边带里)。注意 \(m>1\) 时"过调制",包络发生反转,包络检波失效并产生严重失真。

§8.4 单边带(SSB):带宽省一半

DSB 的上下边带互为镜像,信息重复。用理想带通滤波器只保留一个边带(如 \([\omega_c,\omega_c+\omega_M]\)),得到 SSB:带宽 \(\omega_M\),省一半,功率也更集中。代价是发射端需要陡峭的带通滤波(工程上用相移法实现)。记住结论即可:SSB = 频谱利用率优先的选择。

§8.5 频分复用(FDM):频域"切块"

直觉先行:一条公路,多条车道

广播电台们共享同一片天空:每个电台占一个频段(车道),互不压线。FDM 就是把各路信号搬到不同的载波频率上,再叠加进同一信道;接收端用带通滤波器"按车道取车",各自解调。保护带(车道之间的空隙)防止滤波器不理想造成的串扰。

第 \(i\) 路信号 \(x_i(t)\)(带宽 \(\omega_{M,i}\))搬到载波 \(\omega_{c,i}\),载波间距须大于相邻带宽之和;接收端用中心频率 \(\omega_{c,i}\)、带宽匹配的带通滤波器取出该路。典型例子:AM 广播(各电台间隔 9/10kHz)、有线电视、光纤的波分复用(光的 FDM)。

§8.6 脉冲幅度调制(PAM)与时分复用(TDM)

PAM:用信号的样本值调制脉冲串的幅度(第7章采样的直接应用)。TDM:各路信号按时间轮转,轮流占用信道——第1路发一个样本、第2路发一个、……轮流循环,接收端同步开关分拣。FDM 是"频率上分车道",TDM 是"时间上排班次",两者对偶。TDM 的数字版就是现代电话骨干网与计算机网络的雏形。

§8.9 自测题(答案附后)

基带信号 \(x(t)\) 带宽 5kHz,以 \(f_c=100\)kHz 载波做 DSB-SC 调制,求已调信号的频谱占用范围与总带宽。

答案与解析

频谱占用:95–105kHz 与 −95–−105kHz(实信号频谱共轭对称),总带宽 \(2\times5=10\)kHz。注意:带宽按正频率一侧算 10kHz,若算"双侧跨度"则是 20kHz——工程上报"带宽 10kHz"。

接收端本地载波为 \(\cos(\omega_c t+\pi/3)\),同步解调输出是什么?

答案与解析

\(\dfrac{x(t)}{2}\cos(\pi/3)=\dfrac{x(t)}{4}\)——相位偏差 60° 使信号衰减一半。\(\phi=90°\) 时输出完全消失;这说明同步解调器本质上是"相敏检波器"。

三路语音信号各占 0–4kHz,用 FDM 复用,载波分别取 100、108、116kHz,若用理想带通滤波解调且不留保护带,求复用信号的总带宽,并画出频谱草图。

答案与解析

各路上边带(SSB)互不重叠地排列:100–104、108–112、116–120kHz → 总带宽 120−100=20kHz。若用 DSB 则每路 8kHz、总 24kHz 且需 4kHz 间隔。保护带在真实系统中必须留,否则滤波器过渡带造成串扰。

为什么 DSB-SC 被称为"抑制载波"?含载波 AM 又把载波加回来,图什么?

答案与解析

DSB-SC 频谱中没有载波谱线(\(x\) 无直流时),发射功率全部用于携带信息的边带,功率效率高,但接收端必须自备同步载波。含载波 AM 的权衡:发射端浪费大量功率在载波上(载波不携带信息),换取接收端极简(包络检波,无需同步)——适合"一台发射机、百万台廉价收音机"的广播场景。工程选择永远在两端权衡。

TDM 系统中,4 路信号各需 4kHz 带宽,用 PAM 采样时分复用,求最低总采样率与每路的采样间隔。

答案与解析

每路奈奎斯特率 8kHz,4 路总采样率 32kHz,即每 31.25μs 一个总样本槽;每路样本间隔 125μs(8kHz),4 路轮流占槽。要点:总速率是各路速率之和,TDM 只是把"并列"改成"轮转",信息量不变。

§8.10 动手实验与下章预告

动手实验(MATLAB / Octave,10 分钟玩一遍调制解调)
fs = 1e6;  t = 0:1/fs:0.002;
x = cos(2*pi*1000*t);               % 1kHz 基带单音
c = cos(2*pi*100e3*t);              % 100kHz 载波
y = x .* c;                         % DSB-SC 调制
X = fftshift(fft(x));  Y = fftshift(fft(y));
w = linspace(-pi, pi, numel(t)) * fs/(2*pi);
plot(w/1e3, abs(X)/max(abs(X)), 'b'); hold on;
plot(w/1e3, abs(Y)/max(abs(Y)), 'r');  % 看频谱搬移:±100kHz 两簇
xlim([-120 120]); legend('基带谱', '已调谱');

z = y .* c;                         % 同步解调:再乘载波
[b, a] = butter(6, 10e3/(fs/2));    % 10kHz 低通
xr = 2 * filter(b, a, z);           % 恢复并补增益
plot(t*1e3, x, 'b', t*1e3, xr, 'r--');
legend('原信号', '解调恢复'); title('同步解调验证')
下章预告:第9章 拉普拉斯变换

第4章的傅里叶变换要求信号绝对可积,把不满足条件的信号(如 \(e^{at}u(t)\),\(a>0\))挡在门外。拉普拉斯变换的解法:给信号乘一个衰减因子 \(e^{-\sigma t}\) 再求傅里叶变换——\(j\omega\) 推广为 \(s=\sigma+j\omega\)。拉氏变换 = 广义傅里叶变换,附带一个叫"收敛域"的重要概念。学习前复习:傅里叶变换定义、部分分式分解、\(H(j\omega)\) 与 LCCDE。
