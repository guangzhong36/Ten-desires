全章核心结论一句话:离散时间信号也有连续频谱 \(X(e^{j\omega})\),但它以 \(2\pi\) 为周期;卷积定理依然成立,系统分析依然是频域乘法。

§5.1 定义:离散时间的频谱

直觉先行:频谱为什么是周期的?

回想第 1 章:\(e^{j\omega n}\) 与 \(e^{j(\omega+2\pi)n}\) 是同一个序列(整数点上取值完全相同)。所以"频率"在离散世界是循环的:把 \(\omega\) 转一圈(\(2\pi\)),又回到起点。于是频谱函数 \(X(e^{j\omega})\) 必然每 \(2\pi\) 重复一次——画频谱只需画一个周期,通常选 \([-\pi,\pi]\) 或 \([0,2\pi]\)。

离散时间傅里叶变换对 \[ X(e^{j\omega}) = \sum_{n=-\infty}^{+\infty} x[n]\, e^{-j\omega n}, \qquad x[n] = \frac{1}{2\pi}\int_{2\pi} X(e^{j\omega})\, e^{j\omega n}\, d\omega \]

0 基础解读(逐符号):①分析式把 \(x[n]\) 与"试探序列" \(e^{-j\omega n}\) 逐点相乘求和,问"频率 \(\omega\) 的成分有多少";②合成式在任意长度 \(2\pi\) 的区间上积分(起点随意,常用 \([-\pi,\pi]\));③记号 \(X(e^{j\omega})\) 刻意写成"\(e^{j\omega}\) 的函数",因为频谱随 \(\omega\) 周期变化;④收敛条件:绝对可和 \(\sum|x[n]|<\infty\) 保证级数一致收敛——第 10 章将看到,更一般信号(如 \(a^n u[n]\) 的 \(|a|>1\) 情形)需要引入收敛域概念。

§5.2 常用变换对与推导

例题 5.1 推导 \(a^n u[n]\) 的频谱(必会题)

求 \(x[n]=a^n u[n]\)(\(|a|<1\))的 DTFT。

  1. 代入:\(X(e^{j\omega})=\displaystyle\sum_{n=0}^{\infty} a^n e^{-j\omega n}=\sum_{n=0}^{\infty}(ae^{-j\omega})^n\)。
  2. 几何级数(公比 \(|ae^{-j\omega}|=|a|<1\) 收敛):\(X(e^{j\omega})=\dfrac{1}{1-ae^{-j\omega}}\)。
  3. 读图(例 5.2 将展开):\(|X|=\dfrac{1}{\sqrt{1+a^2-2a\cos\omega}}\)。当 \(0能量集中在低频,是"低通"形状。

例题 5.2 用性质秒算两个经典变换

(a) \(x[n]=\delta[n+1]+\delta[n-1]\);(b) \(x[n]=\left(\dfrac{1}{2}\right)^n\cos\left(\dfrac{\pi n}{4}\right)u[n]\)。

  1. (a) 用 \(\delta\leftrightarrow1\) + 时移:\(X(e^{j\omega})=e^{j\omega}+e^{-j\omega}=2\cos\omega\)。心得:两根对称冲激 = 一条余弦谱。
  2. (b) 用频移性质:\(\cos(\pi n/4)\) 是 \(e^{\pm j\pi n/4}\) 的和,乘序列相当于频谱搬移。
  3. 基序列 \(b^n u[n]\leftrightarrow\dfrac{1}{1-be^{-j\omega}}\)(\(b=1/2\)),频移 \(\pm\pi/4\) 后取半相加。
  4. \(X(e^{j\omega})=\dfrac{1/2}{1-\frac{1}{2}e^{-j(\omega-\pi/4)}}+\dfrac{1/2}{1-\frac{1}{2}e^{-j(\omega+\pi/4)}}\)。验证:\(\omega=0\) 处两项对称,谱值相等,符合实序列共轭对称。

§5.4 差分方程与频率响应

直觉先行:差分方程 = 频域有理分式

对差分方程 \(\sum_k a_k y[n-k]=\sum_k b_k x[n-k]\) 两边取 DTFT,时移变成乘 \(e^{-j\omega k}\),立刻解出 \(H(e^{j\omega})\) 是两个多项式之比——与 CT 的"导数换 \(j\omega\)"完全平行,只是把 \(j\omega\) 换成 \(e^{-j\omega}\)。

LCCDE → 频率响应(DT) \[ H(e^{j\omega}) = \frac{\sum_{k=0}^{M} b_k e^{-j\omega k}}{\sum_{k=0}^{N} a_k e^{-j\omega k}} \]
例题 5.3 一阶系统 \(y[n]-a\,y[n-1]=x[n]\) 的频率响应(必会题)
  1. 取 DTFT:\(Y(e^{j\omega})-a e^{-j\omega}Y(e^{j\omega})=X(e^{j\omega})\)。
  2. 解出:\(H(e^{j\omega})=\dfrac{1}{1-ae^{-j\omega}}\)——与 \(a^n u[n]\) 的频谱同形!这正是"\(h[n]=a^n u[n]\)"的验证。
  3. 幅度谱:\(|H|=\dfrac{1}{\sqrt{1+a^2-2a\cos\omega}}\),相位谱:\(\angle H=-\arctan\dfrac{a\sin\omega}{1-a\cos\omega}\)。
  4. 判型:\(0低通;\(-1高通。仅凭系数 \(a\) 的符号即可判型,非常好用。
图 5-2 理想低通滤波器(离散时间):通带 \(|H|=1\),阻带为 0,频谱每 \(2\pi\) 重复。对应冲激响应是 sinc 序列(无限长、非因果,工程上只能近似)

§5.8 自测题(答案附后)

求 \(x[n]=\left(\dfrac{1}{2}\right)^{|n|}\) 的 DTFT。

答案与解析

\(x[n]=(1/2)^n u[n]+(1/2)^{-n}u[-n-1]\)。第一部分 \(\dfrac{1}{1-\frac{1}{2}e^{-j\omega}}\);第二部分用反转性质(把 \((1/2)^n u[n]\) 反转并延迟 1):\(\dfrac{\frac{1}{2}e^{j\omega}}{1-\frac{1}{2}e^{j\omega}}\)。相加:\(X(e^{j\omega})=\dfrac{1-\frac{1}{4}}{(1-\frac{1}{2}e^{-j\omega})(1-\frac{1}{2}e^{j\omega})}=\dfrac{3/4}{5/4-\cos\omega}\)。注意 \(|X|\) 是实偶函数(序列偶对称 → 频谱实)。

系统 \(y[n]-0.8y[n-1]=x[n]\),求 \(H(e^{j\omega})\),并求 \(|H|\) 在 \(\omega=0\) 与 \(\omega=\pi\) 的值,判断滤波器类型。

答案与解析

\(H(e^{j\omega})=\dfrac{1}{1-0.8e^{-j\omega}}\)。\(\omega=0\):\(|H|=\dfrac{1}{1-0.8}=5\)(放大 5 倍!);\(\omega=\pi\):\(|H|=\dfrac{1}{1+0.8}\approx0.56\)。低频放大、高频削弱 → 低通。极点靠近单位圆(\(a=0.8\)),谐振峰尖锐——\(a\) 越接近 1,低频"隆起"越明显。

用卷积定理求 \(y[n]=x[n]*h[n]\) 的频谱,其中 \(x[n]=(1/2)^n u[n]\),\(h[n]=(1/3)^n u[n]\),并给出 \(y[n]\) 的表达式。

答案与解析

\(Y(e^{j\omega})=\dfrac{1}{(1-\frac{1}{2}e^{-j\omega})(1-\frac{1}{3}e^{-j\omega})}\)。部分分式:\(=\dfrac{3}{1-\frac{1}{2}e^{-j\omega}}-\dfrac{2}{1-\frac{1}{3}e^{-j\omega}}\) → \(y[n]=\left[3\left(\dfrac{1}{2}\right)^n-2\left(\dfrac{1}{3}\right)^n\right]u[n]\)。与 CT 的例题 4.4 流程完全相同,只是 \(j\omega\to e^{-j\omega}\)。

序列 \(x[n]=\cos(\pi n/4)\) 的频谱长什么样?(不要求推导,描述形状即可)

答案与解析

在 \(\omega=\pm\pi/4\) 处各有一根强度 \(\pi\) 的谱线,并在 \(\omega=\pm\pi/4\pm2\pi k\) 处周期重复。注意:\(\cos(\pi n/4)\) 是周期序列(周期 8,因 \(\omega_0/2\pi=1/8\) 有理),故频谱是离散冲激——与 DTFS 完全一致。这也印证了"周期序列 ↔ 冲激谱"的 DT 版本。

Parseval 验证:\(x[n]=(1/2)^n u[n]\) 的能量等于频谱模方的积分平均值。

答案与解析

时域:\(\sum_{n=0}^{\infty}(1/4)^n=\dfrac{1}{1-1/4}=\dfrac{4}{3}\)。频域:\(\dfrac{1}{2\pi}\int_{-\pi}^{\pi}\dfrac{d\omega}{1+\frac{1}{4}-\cos\omega}=\dfrac{4}{3}\) ✓(可用留数或查积分表,数值积分亦可验证)。工程提示:这类校验在数值仿真中极其常用——时频两域能量相等是检查代码错误的最快手段。

§5.9 动手实验与下章预告

动手实验(MATLAB / Octave,10 分钟看频谱)
[H, w] = freqz([1], [1 -0.5]);       % 一阶系统 H = 1/(1-0.5e^{-jw})

legend('a=0.5 低通', 'a=-0.5 高通');

n = 0:30; x = 0.5.^n;                % 数值验证 DTFT
w = linspace(-pi, pi, 200);
X = x * exp(-1j * n' * w);           % 直接按定义求和
plot(w, abs(X), 'b.'); hold on;
plot(w, 1./sqrt(1.25 - cos(w)), 'r--');  % 理论值,应重合
