从 C 到 C++:本章主题如何迁移

如果你能熟练写出 struct Node { int data; struct Node* next; } 这样的 C 代码,那么 C++ 的数据类型对你来说九成是熟面孔:int、double、char、指针,字节数与语义几乎不变。C++ 是 C 的超集,语法向下兼容,但它在类型体系上做了三件大事。

第一,类型更安全。C 的 enum 常量泄漏到全局、能隐式变成整数;C++11 的 enum class 把名字关进作用域,拒绝隐式转换。C 的 (int*)&d 想怎么强转就怎么强转;C++ 提供 static_cast 等四种语义明确的转换,把"窄化转换"列为编译错误。

第二,标准库补齐了 C 的短板。C 的 char[] 要靠 strlen/strcpy 手工维护长度,数组传参退化为指针;C++ 的 std::string 自己管理内存与长度,std::vector 是自动扩容的"安全数组",std::map 直接提供键值对。生产环境里,C 风格字符串与裸数组几乎只出现在遗留代码中。

第三,编译期能力大幅增强。C 的 #define MAX 100 只是文本替换;C++ 的 constexpr 变量与函数在编译期完成计算与类型检查。读完本章,你应该默认使用现代写法。

§1.1 类型总览:从 C 类型表到 C++ 类型表

C++ 的内建类型与 C 几乎一一对应。注意:标准不规定精确字节数,只保证大小关系,下表以最常见的 64 位平台为例,程序应随时用 sizeof 查询。

C 的写法C++ 的写法典型字节(64 位)说明
intint4语义完全相同
longlongWin:4;Linux:8最大陷阱:MSVC 恒 32 位
unsignedunsigned4等价 unsigned int
float/doublefloat/double4/8IEEE 754
无bool1_Bool 现代化身
charchar1符号性实现定义
size_tstd::size_t8有符号对应 ptrdiff_t
long longlong long8跨平台 64 位用它

1.1.1 bool:C 没有的"真正的布尔"

C 直到 C99 才有 _Bool,且本质上是整数。C++ 的 bool 是独立类型,只有 true/false 两个值,任何非零值赋给它都会变成 true。sizeof(bool) 通常是 1,不是 1 位。生产习惯:逻辑判断用 bool,不要用 int 充当标志位。

1.1.2 char 的三大陷阱

  • 符号性未定义:char 是 signed 还是 unsigned 由编译器决定,跨平台读写二进制必须显式用 signed char/unsigned char 存字节
  • char 不是"字符":汉字在 UTF-8 下占 3 字节,char 存不下一个汉字;文本处理用 std::string
  • char 参与算术先提升为 int:char c = 100 + 100; 在有符号 char 上可能溢出,与 C 完全一致

1.1.3 固定宽度整型:C++11 的礼物

<cstdint> 提供 std::int8_t/16_t/32_t/64_t 及无符号版本。生产建议:网络协议、二进制文件、位域计算一律用固定宽度类型,普通计数用 int 或 std::size_t。

易错点 1:long 在 Windows 与 Linux 上字节数不同

Windows(MSVC,LLP64)上 long 是 4 字节,64 位 Linux(GCC,LP64)上是 8 字节。同样的 long x = 3000000000L; 在 Windows 上溢出、在 Linux 上正常。生产规则:需要确定 64 位时写 long long 或 std::int64_t,不要写 long。

示例 1-1 内建类型大小实测
#include <iostream>
#include <cstdint>

int main() {
    std::cout << "long      = " << sizeof(long)        << "\n";  // Windows 上是 4!
    std::cout << "long long = " << sizeof(long long)   << "\n";
    std::cout << "size_t    = " << sizeof(std::size_t)  << "\n";
    std::cout << "int64_t   = " << sizeof(std::int64_t) << "\n";
    return 0;
}

§1.2 变量:声明、初始化与 auto

1.2.1 四种初始化写法

C 只有 int x = 0; 一种写法,C++ 有四种,含义各不相同:

C 的写法C++ 的写法含义
int x = 0;int x = 0;拷贝初始化,兼容 C
无int x(0);直接初始化
无int x{0};列表初始化,禁止窄化,推荐
无int x{};值初始化,归零

生产建议:标量与结构体一律用 {},同时杜绝"忘记初始化"与"窄化截断"两类问题。

1.2.2 未初始化:C 的 UB 文化在 C++ 中的延续

C 里 int x; printf("%d", x); 是未定义行为(UB)。C++ 规矩相同:内置类型默认初始化后值不确定,读取即 UB;类类型调用默认构造函数;而 int x{}; 是值初始化,保证得到 0。全局与静态变量无论哪种写法都零初始化。

易错点 2:auto 推导会剥掉 const 和引用

const int a = 1; auto b = a; 中 b 是 int,不是 const int——auto 按值推导,拷贝了一份。同理 int& r = x; auto r2 = r; 得到 int。需要保留修饰时写 const auto& c = a;。

示例 1-2 变量初始化与 auto 推导
#include <iostream>

struct Student {           // 类类型:有默认构造函数
    int id;                // 无初始化器:值不确定(等价于 C)
    double score = 0.0;    // C++11 默认成员初始化器
};

int main() {
    int a;                 // 默认初始化:值不确定,别读
    int b = 0;             // 拷贝初始化
    int d{0};              // 列表初始化
    int e{};               // 值初始化:确定得到 0

    auto f = 3.14;         // double
    const auto h = 42;     // const int
    std::cout << b << d << e << f << h << "\n";

    Student s1;            // id 不确定,score 是 0.0
    Student s2{};          // 值初始化:id 也归零,推荐
    std::cout << s1.score << s2.id << "\n";
    return 0;
}

1.2.3 auto:类型推导的两面性

auto 不是"动态类型",变量在编译期就已确定类型。它最适合类型名冗长时(std::map<std::string, std::vector<int>>::iterator 写起来痛不欲生)。生产约定:公共接口显式写类型,局部变量放心用 auto,推导可读性差时宁可写全。

§1.3 字面量:C++ 的扩展

示例 1-3 字面量全家福
#include <iostream>

int main() {
    int  dec = 42;           // 十进制
    int  hex = 0x2A;         // 十六进制
    int  bin = 0b101010;     // C++14 起支持二进制
    int  sep = 1'000'000;    // C++14 数字分隔符
    long long ll = 42LL;     // long long 后缀

    double pi = 3.14159;     // 默认 double
    float  f  = 3.14f;       // float 后缀 f

    char ch = 'A';
    auto s = "hello";        // const char[6],以 '\0' 结尾
    auto raw = R"(C:\Users\dev\x)";  // 原始字符串:免转义
    std::cout << dec << hex << bin << sep << ll << pi << f
              << ch << s << raw << "\n";
    return 0;
}

原始字符串是生产利器:写正则、JSON、Windows 路径时免双重转义。语法 R"(内容)",内容里出现 )" 时可加定界符 R"xx(内容)xx"。编码前缀:u8 是 UTF-8(char8_t,C++20 起),u 是 UTF-16,U 是 UTF-32。生产规范:文件存 UTF-8、字符串写 u8 前缀、全程用 std::string 承载。

§1.4 常量:const、constexpr 与编译期计算

1.4.1 const 的局限与 C++ 的修正

C 的 const int N = 100; int a[N]; 在标准 C 里不能保证编译通过;C 的 const 本质是"运行期只读变量"。C++ 修正了这一点:C++ 的 const 整型常量是编译期常量,可用于数组大小、模板参数。但 const 只在编译期检查,不保证对象不在别处被改(const int* 可指向可变对象)。

1.4.2 constexpr:真正的编译期常量

C++11 引入 constexpr,C++14 起 constexpr 函数里允许循环与分支。它比 const 强:值必须在编译期确定。生产替代关系:#define MAX 100 → constexpr int kMax = 100;,后者有类型、有作用域、不污染预处理器。

示例 1-4 const 与 constexpr 的分工
#include <iostream>

constexpr int kMaxItems = 100;              // 替代 #define MAX_ITEMS 100
constexpr int kSquare(int n) { return n * n; }  // constexpr 函数

int main() {
    int arr[kMaxItems];                     // 编译期大小,可以
    int arr2[kSquare(10)];                  // constexpr 函数也能定数组大小

    int n = 0;
    std::cin >> n;
    const int runtime = n;                  // const:运行期只读
    // constexpr int bad = n;               // 编译错误:n 不是编译期常量
    constexpr int kFixed = 2 + 3;           // 正确
    return 0;
}

1.4.3 C++20 的 consteval 与 constinit

consteval 强制函数只能在编译期求值;constinit 要求静态变量用常量初始化。生产上 constexpr 已足够 90% 场景。

§1.5 类型转换:隐式、显式与窄化

1.5.1 隐式转换:与 C 完全一致的规则

整型提升、有符号/无符号混合、double 吸收 float——C 的规则原样继承,C 的坑也全部保留:int 与 unsigned 比较时 int 被转成无符号;有符号溢出仍是 UB。写作时主动避免混用有符号与无符号,std::vector<T>::size() 返回 size_t,与 int 比较前先想清楚。

1.5.2 列表初始化拒绝窄化

int x{300.5}; 是编译错误——double 到 int 是窄化转换。这是 C++ 对 C 最有价值的改进之一:把危险的隐式转换从运行期事故变成编译期错误。而 int x = 300.5; 仍能编译(兼容 C),只是截断成 300。

1.5.3 四种显式转换

转换用途
static_cast有明确定义的转换,日常 95% 用它
const_cast去掉 const;能不用就不用
reinterpret_cast重新解释二进制位;危险,审慎
dynamic_cast多态运行时向下转型(第6章),有 RTTI 开销

C 风格强转 (int)x 是组合拳,编译器不拦任何错误。生产规范:代码中禁止 C 风格强转,统一用四种具名转换,便于 grep 与 review。

示例 1-5 类型转换的正确姿势
#include <iostream>

int main() {
    int i = 300;
    char c = static_cast<char>(i);      // 显式转换:我知道可能截断
    double d = i;                        // 隐式:int → double,无损
    i = static_cast<int>(d);             // double → int,丢弃小数

    // int x{300.5};                     // 编译错误:拒绝窄化
    int y{300};                          // 正确:无损放入

    unsigned u = 1u;                     // 有符号/无符号混用陷阱
    int s = -1;
    std::cout << (s < u) << "\n";        // 输出 0!s 被转成 unsigned

    char a = 100, b = 100;               // 整型提升:char 先转 int 再运算
    char sum = static_cast<char>(a + b); // a+b 是 int,等于 200,再转回

    std::cout << sum << y << "\n";
    return 0;
}

§1.6 字符串:从 char[] 到 std::string

C 字符串的三大痛点,C++ 的三种解法

C 里字符串是"以 \0 结尾的 char 数组":strcpy 不知道目标容量,拼长了缓冲区溢出;strlen 每次 O(n) 扫描;很多人错误地拿 == 去比指针。std::string 一次性解决:内存自动扩容、size() 是 O(1)、== 比较内容。生产铁律:禁止用 C 字符串函数操作裸缓冲区。

C 的写法C++ 的写法差异
strlens.size()O(1) vs O(n)
strcmpa == b直接比内容
strcpys2 = s;自动管容量
strcats2 += s;自动扩容
strstrs.find(t)返回下标,失败 npos
示例 1-6 std::string 常用操作
#include <iostream>
#include <string>

int main() {
    std::string s = "hello";
    s += " world";                  // 拼接,自动管理容量
    std::cout << s.size() << "\n";  // O(1),不是 strlen 的 O(n)
    std::cout << (s == "hello world") << "\n";   // 内容比较,不是指针!
    std::cout << s.substr(0, 5) << "\n";         // 子串 "hello"
    std::cout << s.find("world") << "\n";       // 下标 6;找不到返回 npos
    s.replace(6, 5, "C++");         // 替换 [6, 11)
    const char* cstr = s.c_str();   // 与 C 接口互操作:只读 C 字符串

    std::string msg = "count=" + std::to_string(42);   // 数值转字符串
    int n = std::stoi("42");        // 字符串转数值

    // 只读视图 string_view(C++17):零拷贝,只做函数参数
    std::string_view sv = "只读数据";
    std::cout << n << msg << cstr << sv.size() << "\n";
    return 0;
}
工程建议:编码与性能

编码:现代项目的字符串策略是"内部统一 UTF-8 的 std::string,只在 I/O 边界做编码转换"。不要用 std::wstring 处理业务数据——Windows 上是 UTF-16,Linux 上是 UTF-32,行为不一致。性能:小字符串优化(SSO)让小串(约 15 字符内)不分配堆内存;拼接大量小串用 reserve() 预分配。

§1.7 复合类型入门:array、vector 与 map

1.7.1 std::array:知道长度的固定数组

C 的数组传参退化为指针,函数里拿不到长度——这是 C 数组最大的设计缺陷。std::array<T, N> 是值语义的数组,能 size()、at() 越界检查、能整体拷贝赋值,性能与 C 数组相同。

1.7.2 std::vector:生产环境的默认容器

std::vector<T> 对应 C 里"malloc + 手工 realloc"的场景,但自动管理:满了翻倍扩容,析构自动释放。注意:扩容会使迭代器与引用失效;删除元素用 erase-remove 惯用法(第3章详述)。

示例 1-7 array、vector 与 map 入门
#include <iostream>
#include <array>
#include <vector>
#include <map>

int main() {
    // at() 越界抛异常;[] 越界是 UB(和 C 一样)
    std::array<int, 5> a{1, 2, 3, 4, 5};
    std::cout << a.size() << a.at(0) << "\n";

    std::vector<int> v;                 // 动态数组,自动扩容
    v.push_back(10);
    v.push_back(20);
    v.emplace_back(30);                 // 原地构造,免拷贝
    v[1] = 99;
    std::cout << v.size() << v.front() << v.back() << "\n";

    for (int x : v) {                   // 范围 for:现代遍历正统写法
        std::cout << x << " ";          // 10 99 30
    }

    std::map<std::string, int> scores;  // 红黑树,按键有序
    scores["张三"] = 90;                 // 键不存在则插入
    std::cout << scores["张三"] << scores.size() << "\n";

    for (const auto& [name, score] : scores) {   // 结构化绑定(C++17)
        std::cout << name << ":" << score << " ";
    }
    return 0;
}
易错点 3:vector 越界与迭代器失效

对 std::vector 用 [] 越界访问是未定义行为——它不会检查,和 C 数组一样可能悄悄踩坏内存。需要安全访问用 v.at(i)(越界抛 std::out_of_range),需要性能用 [] 并先保证下标合法。另外,push_back 导致扩容时,之前保存的迭代器、指针、引用全部失效——这是 C 里不存在的"新坑",第3章专门讲。

§1.8 枚举与类型别名

1.8.1 从 C 的 enum 到 enum class

C 的 enum Color { RED }; 把 RED 泄漏到全局作用域,且枚举值能隐式转 int、int 也能隐式转回枚举——类型形同虚设。C++11 的 enum class 是真正的强类型:名字在作用域内,不隐式转 int,还能指定底层类型(默认 int,可改成 char 省空间)。

示例 1-8 强类型枚举与类型别名
#include <iostream>
#include <vector>

// C 的写法:enum Color { RED, GREEN, BLUE };  // 名字泄漏进全局
// C++11 强类型枚举:作用域隔离,不隐式转整数
enum class Color : int { RED, GREEN, BLUE };
enum class Status : char { OK = 0, WARN = 1, ERR = 2 };

int main() {
    Color c = Color::GREEN;
    // int n = c;                    // 编译错误:不能隐式转整数
    int n = static_cast<int>(c);     // 必须显式转换

    // C 用 typedef,现代 C++ 用 using(可用于模板,更可读)
    using Byte = unsigned char;
    using IntList = std::vector<int>;

    IntList v{1, 2, 3};
    Byte b = 200;
    std::cout << static_cast<int>(b) << v.size() << "\n";
    return 0;
}

1.8.2 别名不是新类型

using Id = int; 只是别名,Id 与 int 完全互通。若需要"防混淆的新类型"(学号与工号都是 int 但不应混用),需要包装结构体等手段——第14章"新类型模式"会讲。

用 std::string 把 "apple,banana,cherry" 按逗号切分,打印每段并统计总字符数。写出完整程序。

参考答案
#include <iostream>
#include <string>
#include <vector>
#include <sstream>

int main() {
    std::string line = "apple,banana,cherry";
    std::vector<std::string> parts;
    std::string token;
    std::istringstream ss(line);
    while (std::getline(ss, token, ',')) {
        parts.push_back(token);
    }
    std::size_t total = 0;
    for (const auto& p : parts) {
        std::cout << p << "\n";
        total += p.size();
    }
    std::cout << "总字符数: " << total << "\n";
    return 0;
}

#include <iostream>
#include <string>

// 任务 2:constexpr 常量,替代 #define
constexpr double kPassScore = 60.0;

// 任务 3:强类型枚举
enum class Grade { EXCELLENT, GOOD, PASS, FAIL };

Grade classify(double score) {          // 按分数返回等级
    if (score >= 90.0) return Grade::EXCELLENT;
    if (score >= 75.0) return Grade::GOOD;
    if (score >= kPassScore) return Grade::PASS;
    return Grade::FAIL;
}

// 任务 1:学生结构体
struct Student {
    int id;                 // 学号
    std::string name;       // 姓名
    bool male;              // 性别:true=男
    char classCode;         // 班级代号 'A'/'B'
    double score;           // 成绩
};

// 附加任务:按学号查找,返回下标,未找到返回 -1
int findById(const std::vector<Student>& list, int targetId) {
    for (std::size_t i = 0; i < list.size(); ++i) {
        if (list[i].id == targetId) return static_cast<int>(i);
    }
    return -1;
}
参考答案要点(第二部分:main 主流程)
int main() {
    // 任务 4:vector 登记学生,{}-列表初始化
    std::vector<Student> students;
    students.push_back({1001, "张三", true,  'A', 92.5});
    students.push_back({1002, "李四", false, 'A', 78.0});
    students.push_back({1003, "王五", true,  'B', 55.5});
    students.push_back({1004, "赵六", false, 'B', 87.0});

    // 任务 5:统计,显式转换避免整数除法
    std::map<Grade, int> gradeCount;    // 等级 -> 人数
    double sum = 0.0;
    int passed = 0;
    for (const auto& s : students) {    // 任务 7:const auto& 避免拷贝
        sum += s.score;
        if (s.score >= kPassScore) ++passed;
        ++gradeCount[classify(s.score)];
    }
    double avg = sum / static_cast<double>(students.size());
    double passRate = static_cast<double>(passed) / students.size() * 100.0;

    // 任务 6:格式化输出
    std::cout << std::fixed << std::setprecision(2);
    std::cout << "总人数: " << students.size() << "\n";
    std::cout << "平均分: " << avg << "\n";
    std::cout << "及格率: " << passRate << "%\n";
    for (const auto& [grade, cnt] : gradeCount) {   // 结构化绑定遍历 map
        std::cout << "等级 " << static_cast<int>(grade) << " 人数: "
                  << cnt << "\n";
    }

    // 附加任务:查找并打印
    int pos = findById(students, 1002);
    if (pos >= 0) std::cout << "学号 1002 是 " << students[pos].name << "\n";
    return 0;
}

设计说明:全程序零 #define、零 C 风格强转、零裸数组;先 std::fixed 再 setprecision(2) 保证两位小数。除法写 sum / static_cast<double>(students.size()) 而非 sum / students.size(),是显式表达"我要浮点除法"——后者通常也能工作,但隐式转换意图不明,生产规范要求显式。
